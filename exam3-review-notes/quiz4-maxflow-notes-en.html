Q1. Residual network equals the original network

Network G = (V, E), s, t ∈ V, capacities c(e), valid flow f. The residual network Gf is equal to the given network G. Which must be true?

  1. The given flow f is equal to zero.
  2. The given flow f is a max flow.
  3. There is no path from s to t in Gf.
  4. There is no path from s to t in G.

Answer: (a) f is the zero flow.

  • For e = (u,v) ∈ E, the residual forward edge has capacity c(e) − f(e). Gf = G forces c(e) − f(e) = c(e), so f(e) = 0 on every edge.
  • With f = 0 there are no backward edges either, so the residual network is exactly G. Consistent.

(b): the zero flow is max only if the max-flow value is 0 — not guaranteed. (c)(d): since Gf = G these are the same claim; G may well contain an s–t path while f = 0.

Q2. size(f) = cap(L,R) (select all)

Valid flow f and an s–t separating cut (L, R) with size(f) = cap(L,R). Select ALL statements that are always true.

  1. The given flow f is a max flow.
  2. The given cut (L, R) is a min-cut.
  3. For every other valid flow f′, cap(L,R) ≥ size(f′).
  4. For every other cut (L′, R′), cap(L′,R′) ≥ size(f).

Answer: (a), (b), (c), (d) — all of them.

  • Weak duality: for ANY flow f′ and ANY cut, size(f′) ≤ cap. This needs no hypothesis → (c), (d) are true.
  • Adding size(f) = cap(L,R) sandwiches both sides: no flow beats f → (a); no cut beats (L,R) → (b).

Point: (c) and (d) are weak duality itself — statements that need no premise. A classic select-all trap.

Q3. Every capacity +1: the new max flow

Valid flow f with size(f) > 0. Increase every edge capacity by 1, forming a new network; f′ denotes a max flow in the new network. Which must be true?

  1. size(f′) ≥ size(f) + cap(L,R), where (L,R) is a min cut.
  2. size(f′) ≥ size(f) + 1.
  3. size(f′) is never greater than size(f).
  4. size(f′) ≤ size(f) + 1.

Answer: (b) size(f′) ≥ size(f) + 1.

Proof. Let F′ be the new max-flow value. For any cut (L,R), the new cut capacity is capold(L,R) + n(L,R) (n = number of L→R edges). At a minimizing cut (L*,R*):

  • F′ = capold(L*,R*) + n(L*,R*) ≥ Fold + n(L*,R*).
  • size(f) > 0 gives Fold > 0, so capold(L*,R*) > 0, so the cut contains at least one edge: n(L*,R*) ≥ 1.
  • ∴ F′ ≥ Fold + 1 ≥ size(f) + 1. (f stays valid in the new network, so F′ ≥ size(f) is trivial.)

(a) counterexample: single s→t edge, cap 5. size(f) = 5, min-cut cap 5, but new max is 6 < 5+5 = 10. (c) counterexample: same network, 6 > 5. (d) counterexample: two parallel s→t edges of cap 1, f = max flow (value 2); new max = 4 > 2+1 = 3.

Q4. The s-reachable set in the residual graph is a min cut

f* is a valid max flow. S = { v ∈ V | there is a path from s to v in Gf* }. True or False: {S, V−S} is a minimum-capacity st-cut.

Group of answer choices: True / False

Answer: True.

The standard construction from the max-flow min-cut proof:

  • t ∉ S (else an augmenting path exists), so (S, V−S) is an st-cut.
  • S→(V−S) edges are all saturated (otherwise a residual forward edge would reach across). (V−S)→S edges carry zero flow (otherwise a residual backward edge would reach back).
  • ∴ cap(S, V−S) = f*out(S) − f*in(S) = size(f*) → a min cut.

Q5. Are all cut-crossing edges saturated?

f* is a valid max flow; (L,R) is a minimum-capacity st-cut. True or False: every edge e with endpoints on different sides of (L,R) satisfies f(e) = c(e).

Group of answer choices: True / False

Answer: False.

Trap: "endpoints on different sides" includes R→L edges too.

  • L→R edges: saturated, yes (f(e) = c(e)).
  • R→L edges: carry zero flow — size(f) = fout(L) − fin(L) = cap(L,R) forces fin(L) = 0.

Counterexample: edges (s,t) cap 5 and (t,s) cap 3. Min cut ({s},{t}) has cap 5. Edge (t,s) straddles the cut but f(t,s) = 0 ≠ 3 = c.

The R→L edge (t,s) crosses the min cut but carries zero flow.

Q6. Always-true statements about a flow (select all)

Valid flow f. Select ALL always-true statements.

  1. If f is a maximum flow, then every edge (s,v) is saturated OR every edge (w,t) is saturated.
  2. If there is no path from s to t in the residual network Gf, then f is a maximum flow.
  3. If f is a maximum flow, then every st-cut has capacity equal to the size of f.
  4. If f is a maximum flow, then the residual network Gf is never strongly connected.

Answer: (b), (d).

  • (b) true: no augmenting path ⟹ max flow — the heart of Ford-Fulkerson correctness.
  • (d) true: a max flow leaves no s–t path in Gf; strong connectivity would require s to reach t. So Gf can never be strongly connected.

(a) counterexample: s→a, s→b (cap 10 each), a→x, b→x (cap 3 each), x→t (cap 10). Max flow = 6, yet (s,a) carries 3/10 and (x,t) carries 6/10 — both unsaturated. (c): only min cuts have capacity equal to size(f); other cuts are larger.

Q7. Residual capacities from f(e) = 7, c(e) = 10

Valid flow f. Edge e = (u,v), c(e) = 10, f(e) = 7. Edge (v,u) is not in the original network. Which is true about Gf?

  1. The residual network has an edge (u,v) with capacity 10, and edge (v,u) with capacity 7.
  2. The residual network has an edge (u,v) with capcity 3 and edge (v,u) with capcity 7.
  3. The residual network has only the edge (u,v) with capacity 7.
  4. The residual network has only the edge (u,v) with capcity 3.

Answer: (b).

  • Forward edge (u,v): residual capacity = c − f = 10 − 7 = 3.
  • Backward edge (v,u): residual capacity = f = 7 — it appears in the residual network even though (v,u) was never in G.

Memorize: forward = remaining capacity c−f; backward = cancellable flow f.

Q8. Always-true statements about Ford-Fulkerson (select all)

Select ALL always-true statements about the Ford-Fulkerson algorithm.

  1. Every round increases the flow value by at least one.
  2. The algorithm terminates after at most |E| rounds.
  3. The runtime depends on the numerical value of the maximum flow.
  4. Choosing an arbitrary augmenting path always gives a polynomial-time algorithm in the input size.

Answer: (a), (c). (Under integer capacities — the course's standard setting.)

  • (a) true: integer capacities ⟹ integer bottleneck on each augmenting path, so every round adds ≥ 1.
  • (c) true: runtime O(m·C) depends on the max-flow value C → pseudo-polynomial.

(b) counterexample: the classic 4-node bad example with capacity C needs 2C rounds, exceeding |E| for large C. (d): arbitrary path choice can be exponential and may not even terminate on irrational capacities. Polynomial time needs shortest augmenting paths (Edmonds-Karp).

Q9. Uniqueness of max flow / min cut (select all)

Positive integer capacities. Select ALL always-true statements.

  1. All maximum flows have the same value.
  2. All minimum cuts have the same capacity.
  3. If the maximum flow is unique, then the minimum cut is also unique.
  4. If the minimum cut is unique, then the maximum flow is also unique.

Answer: (a), (b).

  • (a)(b) true: by definition of "maximum"/"minimum" the value is unique. (That says nothing about the flow or cut themselves being unique!)

(c) counterexample: s→a (cap 2), a→t (cap 2), s→t (cap 1). The max flow is forced to {s→a:2, a→t:2, s→t:1} (value 3) — unique. But both ({s},{a,t}) and ({s,a},{t}) are min cuts (cap 3). Not unique.

(d) counterexample: s→a (1), s→b (1), a→t (5), b→t (5), a→b (1), b→a (1). The unique min cut is ({s},{a,b,t}) (cap 2; every other cut ≥ 3). Two distinct max flows of value 2: {a→t:1, b→t:1} and {a→b:1, b→t:2}. → unique min cut does NOT imply unique max flow.

Counterexample for (d): unique min cut, non-unique max flow.

Q10. All L→R edges saturated ⟹ max flow?

Valid flow f, st-cut (L,R). Every edge e = (u→v) with u ∈ L, v ∈ R satisfies f(e) = c(e). True or False: f is a maximum flow.

Group of answer choices: True / False

Answer: False.

size(f) = fout(L) − fin(L) = cap(L,R) − fin(L). Saturated L→R edges aren't enough — positive flow on R→L edges drags size(f) below cap(L,R).

Counterexample: (s,t) cap 5 with f = 5 (saturated ✓), (t,s) cap 3 with f = 2. Valid flow (net 3 out of s, net 3 into t), value 3. But the max flow is 5 (send 0 back on (t,s)). All L→R edges saturated, yet f is not max.

Same trap as Q5: never forget the R→L direction.

Checklist

  • State the residual-edge capacity formulas (forward c−f, backward f).
  • Prove weak duality size(f) ≤ cap(L′,R′).
  • Explain size(f) = cap(L,R) ⟹ f max and (L,R) min via the sandwich.
  • Prove the new max flow grows by at least 1 after +1 capacities.
  • Prove the residual reachable set is a min cut (L→R saturated, R→L zero).
  • Remember "edges across a cut" go both ways (Q5, Q10 traps).
  • Use the identity size(f) = fout(L) − fin(L).
  • Distinguish Ford-Fulkerson's pseudo-polynomial bound from Edmonds-Karp.
  • Distinguish uniqueness of the max-flow value from uniqueness of the flow (Q9 counterexamples).
  • Relate "no s–t path in Gf" to strong connectivity.
