Q1. After +1 capacity on every edge, is the max flow still valid?

Flow network G = (V, E), source s, sink t, capacities c(e). f is a max s-t flow. Increase every edge's capacity by 1. True or False: f is a valid flow in the new network.

(A) True   (B) False

Answer: (A) True.

Check the two validity conditions:

  • Capacity constraint: 0 ≤ f(e) ≤ c(e) < c(e)+1 — still satisfied.
  • Flow conservation: f(e) itself is unchanged — still satisfied.

Key: validity is a condition on the flow values, not the capacities. Larger capacities can't invalidate an existing flow.

Q2. After +1 capacity on every edge, is the max flow still maximum?

Same setup as Q1. True or False: f is still a max s-t flow in the new network.

(A) True   (B) False

Answer: (B) False.

Counterexample: single edge s → t with capacity 1. Max flow = 1. After raising capacity to 2, the new max flow is 2, but the old f has value 1 — no longer maximum.

After +1 capacity the old flow (value 1) is valid (Q1) but not maximum (Q2).

Lesson: valid ≠ maximum. Q1 and Q2 test exactly this distinction.

Q3. Unit capacities: max flow value vs edge-disjoint paths

Directed flow network, every edge has capacity c(e) = 1. Max s-t flow value is k. Which is true?

(A) G contains at most k edge-disjoint s-t paths.   (B) G contains at least k edge-disjoint s-t paths.
(C) G contains exactly k edge-disjoint s-t paths.   (D) None of the above.

Answer: (C). Menger's theorem (edge version): in a unit-capacity network, max flow value = maximum number of edge-disjoint s-t paths.

  • ≥ k direction: Integral flow theorem — integer capacities admit an integer max flow. Flow decomposition of a value-k integer flow yields k s-t paths each carrying 1 unit; unit capacities force them edge-disjoint.
  • ≤ k direction: k+1 edge-disjoint paths would give a flow of k+1 (1 unit each), contradicting max flow = k.

Note: strictly speaking (A) and (B) are also true as weaker statements. (C) is the intended answer capturing the full theorem.

Q4. Maximum number of Ford-Fulkerson iterations

Ford-Fulkerson on an integer-capacity network. Max flow value is C. What is the maximum number of main-loop iterations?

(A) O(|V|·|E|)   (B) O(|E|·C)   (C) C   (D) |E|

Answer: (C) C.

  • Integer capacities → integer bottleneck on each augmenting path, so every augmentation raises the flow by at least 1.
  • Flow value can never exceed C, so at most C iterations.

Careful: (B) O(|E|·C) is the total runtime (O(|E|) per residual-graph search). The question asks for the iteration count, so (C).

Q5. Ford-Fulkerson starting from a nonzero flow

Integer capacities, f a valid integer s-t flow. Run Ford-Fulkerson starting from f instead of zero flow. True or False: it terminates and finds a max s-t flow.

(A) True   (B) False

Answer: (A) True.

  • The residual graph Gf can be built from any feasible flow — it need not be zero.
  • Integer capacities and integer f → integer residual capacities → each augmentation adds ≥ 1 → terminates in finite steps.
  • Correctness (no augmenting path ⟹ max flow) holds regardless of the starting flow.

Same idea as MF5's max feasible flow: start from a feasible flow and augment on a modified residual graph.

Q6. If v(f) = C(A,B), then…?

Cut (A, B) with s ∈ A, t ∈ B; flow f with v(f) = C(A, B). Which must be true?

(A) f is a maximum flow.   (B) (A, B) is a minimum cut.
(C) Both A and B.   (D) Neither A nor B.

Answer: (C) Both A and B.

Weak duality: for any flow f′ and any cut (A′, B′), v(f′) ≤ C(A′, B′).

  • No flow can beat v(f) (every flow ≤ C(A,B) = v(f)) → f is a max flow.
  • No cut can beat C(A,B) (every cut ≥ v(f) = C(A,B)) → (A,B) is a min cut.

This is the core idea of the max-flow min-cut proof: a flow–cut pair attaining the same value certifies both as optimal.

Q7. Multiply every capacity by k

Integer capacities, max flow value F. Multiply every edge capacity by a positive integer k. What is the new max flow value?

(A) F + k   (B) k·F   (C) Fk   (D) F

Answer: (B) k·F.

  • ≥ kF: k·f* (f* the old max flow) is feasible in the scaled network with value kF.
  • ≤ kF: any flow g in the scaled network divided by k is feasible in the original with value v(g)/k ≤ F, so v(g) ≤ kF.

Capacity constraints are linear, so the scale factor passes straight through.

Q8. Remove an edge carrying zero flow

f is a maximum flow with f(e) = 0 on edge e = (u,v). Remove e. Does the max flow value change?

(A) Always decreases.   (B) Never changes.
(C) Depends on whether e is in a minimum cut.   (D) None of the above.

Answer: (B) Never changes.

  • f(e) = 0, so f is still feasible in G − {e} with value v(f) → new max flow ≥ v(f).
  • Removing edges can never increase the max flow → new max flow ≤ v(f).
  • Hence the new max flow equals v(f). Unchanged.

Trap (C): even if e lies in some min cut, f(e) = 0 means it contributes nothing to that cut's capacity, so the cut value is unaffected.

Q9. Is a max flow's residual graph a DAG?

f is a maximum flow. Is the residual graph Gf guaranteed to be a DAG?

(A) Yes   (B) No

Answer: (B) No.

Counterexample: if 0 < f(e) < c(e) on edge e = (u,v), the residual graph contains both the forward edge (u,v) and the backward edge (v,u) — a 2-cycle u → v → u. Not a DAG.

0 < f(e) < c(e) → both directions in the residual graph → a cycle.

Note: a max flow's residual graph is only guaranteed to have no s–t path (that's the definition of max flow). Cycles are fine.

Q10. When does a minimum cut stay minimum?

(A, B) is a minimum cut. Increase one edge e's capacity by 1. Under what condition is (A, B) guaranteed to remain a minimum cut?

(A) e ∈ A×B   (B) e ∉ A×B   (C) e ∈ B×A   (D) Always

Answer: (B) e ∉ A×B.

  • Cut capacity C(A,B) = Σe ∈ A×B c(e). If e ∉ A×B, C(A,B) is unchanged.
  • Every other cut's capacity stays the same or increases (never decreases).
  • Hence (A, B) remains minimum.

Note: (C) e ∈ B×A is also sufficient (B→A edges don't count in cut capacity), but (B) is the most general condition and the intended answer.

  • State and prove Menger's theorem (edge version) in both directions.
  • Distinguish Ford-Fulkerson's iteration bound C from its O(mC) runtime.

  • Explain weak duality v(f) ≤ C(A,B) and "equal value ⟹ both optimal".
  • Prove max-flow scaling under capacity multiplication.
  • Prove removing a zero-flow edge doesn't change the max flow.
  • Draw the residual 2-cycle example.
