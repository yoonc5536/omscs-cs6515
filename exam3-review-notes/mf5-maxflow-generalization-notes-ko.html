1. Max-flow with demands — feasible flow

Max-flow 문제의 일반화: 각 edge e에 demand(수요) d(e) >= 0이 추가된다. 목표는 feasible flow(가능 흐름)를 찾는 것:

  • d(e) <= f(e) <= c(e) — flow는 demand 이상, capacity 이하.
  • Flow conservation — s, t를 제외한 모든 internal vertex에서 flow in = flow out (기존과 동일).

순서: 1) feasible flow가 존재하는지 판정, 2) 존재하면 최대 크기 feasible flow로 augment.

2. 퀴즈 — Feasible flow example

Q. Directed graph의 각 edge에 demand(녹색)와 capacity(빨강)가 표시되어 있다. Edge sa, sb, sc, ad, ae, be, cf, dc, dt, ed, fe, ft마다 demand와 capacity를 만족하는 valid flow 값을 써라.

확인 방법: 각 edge마다 d(e) <= f(e) <= c(e)를 만족하고, s, t를 제외한 모든 정점에서 flow in = flow out이면 정답. (예: (s,a)가 "최소 2, 최대 8"이면 f(sa)는 2 이상 8 이하여야 한다.)

트랜스크립트의 정답 슬라이드는 그림이라 텍스트로 추출되지 않았다 — 위 조건으로 직접 검증하자.

3. Reduction 개요 — max-flow를 black box로

Feasible flow 문제를 max-flow 문제로 reduce한다. Max-flow 알고리즘을 black box(내부를 건드리지 않는 서브루틴)로 쓴다:

  1. Feasible flow 입력 (G, c(e), d(e))을 변환 함수 g로 max-flow 입력 (G', c'(e))으로 바꾼다. (Demand는 없애고, capacity와 그래프에 인코딩.)
  2. Black box max-flow를 G'에 돌려 해 f'를 얻는다.
  3. 변환 함수 h로 f'를 원래 문제의 feasible flow f로 바꾼다.

4. Reduction — 정점 (s', t' 추가)

새 directed graph G': 원래 그래프 G를 그대로 두고, 새 start s'와 새 end t'를 추가. 원래의 s, t는 이제 internal vertex가 된다.

5. Reduction — 원래 edge (capacity shift)

G의 edge는 G'에 그대로 두되, capacity를 demand만큼 shift한다:

c'(e) = c(e) - d(e)

아이디어: G'에서의 flow 0은 G에서의 flow d(e)에 대응. 즉 f'를 f보다 d만큼 내린 것으로 본다. G'에서 flow가 0 이상이면 G에서는 demand를 만족하고, G'에서 c'(e)를 지키면 G에서는 c(e)를 지킨다.

예 (4정점): (s,a)는 (d=3, c=10) → c'=7. (a,t): (7, 8) → c'=1. (a,b): (1, 5) → c'=4. (b,t): (2, 6) → c'=4. (s,b): (d=4, c=9) → c'=5.

6. Reduction — 새 edge (불균형 offset)

Shift만 하면 문제가 생긴다: G'에서 zero flow는 valid하지만, 대응되는 G의 flow(d(e)씩)는 정점 a에서 flow in 3 ≠ flow out 8이라 valid하지 않다. 이 불균형을 offset하기 위해:

  • 각 정점 v마다 edge s' → v, capacity = v로 들어오는 총 demand (d_in(v) = Σ_u d(uv)).
  • 각 정점 v마다 edge v → t', capacity = v에서 나가는 총 demand (d_out(v) = Σ_w d(vw)).

예: s'→a: 3, s'→t: 7+2=9, s'→b: 5, s'→s: 0 / s→t': 3+4=7, a→t': 1+7=8, t→t': 0, b→t': 2.

G' 구성: 원래 edge는 c' = c − d, s'→v (d_in), v→t' (d_out), t→s (∞).

7. Reduction — t → s edge (무한대)

원래의 s, t는 G'에서 internal vertex라 flow in = flow out을 만족해야 한다. 원래 그래프에서는 s로 들어오는 flow도, t에서 나가는 flow도 없었다. 해결: s에서 나가는 flow = t로 들어오는 flow이므로, t → s edge (capacity 무한대)를 추가해 t의 outflow를 s로 되돌린다. 이로써 G' 구성이 완성된다.

8. Saturating flow — D

D = 원래 네트워크의 총 demand = Σ_e d(e) = Σ_v d_in(v) = Σ_v d_out(v).

  • s'에서 나가는 총 capacity = Σ_v d_in(v) = D.
  • t'로 들어오는 총 capacity = Σ_v d_out(v) = D.
  • 따라서 G'의 어떤 flow f'도 |f'| ≤ D.
Saturating flow: |f'| = D인 flow — s'의 모든 outgoing edge와 t'의 모든 incoming edge가 완전히 포화된다. 이는 곧 maximum flow다.
Lemma: G에 feasible flow가 존재 ⟺ G'에 saturating flow가 존재.

9. 증명 (방향 1) — saturating → feasible

Saturating flow f'에서 f(e) = f'(e) + d(e)로 구성 (shift를 되돌림).

  • Demand: f'(e) ≥ 0 → f(e) ≥ d(e). ✓
  • Capacity: f'(e) ≤ c'(e) = c(e) − d(e) → f(e) ≤ c(e). ✓
  • Conservation: f'는 valid하므로 f'_in(v) = f'_out(v). Saturating이므로 f'(s'→v) = d_in(v). 대수 계산: f'_in(v) = d_in(v) + Σ_u(f(uv) − d(uv)) = f_in(v). 마찬가지로 f'_out(v) = f_out(v). 따라서 f_in(v) = f_out(v). ✓

핵심: s'→v edge의 capacity를 d_in(v)로 둔 것이 shift의 불균형을 정확히 상쇄한다.

10. 증명 (방향 2) — feasible → saturating

Feasible flow f에서 f'를 구성:

  • 원래 edge: f'(e) = f(e) − d(e) (demand만큼 내림).
  • s'→v: capacity까지 풀로 (d_in(v)), v→t': 풀로 (d_out(v)) — saturating을 노리므로.
  • t→s: flow를 |f| (f의 크기)로 둔다.
  • Non-negative: f(e) ≥ d(e) → f'(e) ≥ 0. ✓
  • Capacity: f(e) ≤ c(e) → f'(e) ≤ c(e) − d(e) = c'(e). ✓
  • Conservation: f'_in(v) = d_in(v) + Σ_u(f(uv) − d(uv)) = f_in(v), f'_out(v) = f_out(v). f가 valid이므로 f'도 valid. s', t'를 제외한 모든 정점(원래 s, t 포함)에서 성립. ✓

모든 s'→v, v→t'가 포화 → |f'| = D → saturating.

11. Max feasible flow — residual graph 수정

Feasible flow f를 찾았으면, Ford-Fulkerson/Edmonds-Karp처럼 augment해서 최대 크기로 만든다. 차이점 두 가지:

  1. Zero flow가 아니라 feasible flow f에서 시작.
  2. Residual graph의 reverse edge capacity가 다르다: flow를 demand 밑으로 내릴 수 없으므로, 줄일 수 있는 양은 f(e) − d(e)다.

수정된 residual graph (현재 flow f 기준):

  • Forward edge v→w: capacity c(e) − f(e) (남은 여유, 기존과 동일).
  • Reverse edge v→w (원래 w→v에 flow가 있을 때): capacity f(e) − d(e) (demand까지만 줄일 수 있음). 기존에는 f(e)였다.

s–t augmenting path가 없을 때까지 반복 → maximum size feasible flow.

12. 퀴즈 — Reduction example

Q. Feasible flow 입력 그래프 G와 reduction으로 만든 G'이 그림으로 주어졌다 (t→s 보라색 edge의 capacity는 무한대, 그림에 N으로 표시). G'의 capacity를 구하라: (s',a), (s',b), (s',c), (s',d), (s',e), (s',f), (s',t), (a,t'), (b,t'), (c,t'), (d,t'), (e,t'), (f,t'). 그리고: G'에 saturating flow가 있는가? 원래 G에 feasible flow가 있는가?

풀이법:

  • (s',v) = d_in(v): G에서 v로 들어오는 모든 edge의 demand 합.
  • (v,t') = d_out(v): G에서 v에서 나가는 모든 edge의 demand 합.
  • 원래 edge (u,v)의 capacity는 c − d.
  • D = Σ d(e). Max-flow를 돌려 |f'| = D이면 saturating → Lemma에 의해 G에 feasible flow 존재.

트랜스크립트의 정답 슬라이드는 그림이라 수치 추출이 안 됐다 — 위 공식으로 직접 계산하자.

체크리스트

  • Feasible flow의 정의 (d(e) ≤ f(e) ≤ c(e) + conservation)를 쓸 수 있다.
  • Reduction의 g (입력 변환)와 h (해 변환) 역할을 설명할 수 있다.
  • G' 구성 4단계 (s'/t' 추가, c' = c − d, s'→v/v→t', t→s ∞)를 그릴 수 있다.
  • s'→v capacity = d_in(v), v→t' capacity = d_out(v)인 이유를 설명할 수 있다.
  • Saturating flow의 정의와 |f'| ≤ D를 설명할 수 있다.
  • Lemma 양방향 증명의 구성 (f = f' + d / f' = f − d)을 쓸 수 있다.
  • 수정된 residual graph (reverse = f − d)로 max feasible flow를 구하는 과정을 설명할 수 있다.
