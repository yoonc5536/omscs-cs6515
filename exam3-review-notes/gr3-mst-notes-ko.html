1. Greedy approach

Greedy: 부분 해(partial solution)에서 다음 한 수로 locally optimal한 선택을 한다. 언제 global optimum에 도달하는가?

  • Knapsack에서는 greedy가 실패하는 예가 있다 (DP로 해결).
  • MST에서는 greedy가 동작한다 — 이 강의의 주제.

2. MST 문제

입력: undirected graph G, 각 edge e의 weight w(e).

목표: 여전히 connected인 최소 크기의 subgraph — 즉 tree. 그 중 weight(합)가 최소인 minimum weight spanning tree.

Spanning tree라고 부르는 이유: connected + tree (forest가 아님)를 강조.

3. 트리의 기본 성질

  • Tree = connected + acyclic.
  • n개 정점인 tree는 정확히 n − 1개의 edge를 갖는다. (연결하려면 최소 n−1개, 더 많으면 cycle.)
  • Tree에서는 모든 정점 쌍 사이에 정확히 하나의 path가 존재한다. (0개면 disconnected, 2개 이상이면 cycle.)
증명에 쓰는 판정법: connected + edge가 정확히 n−1개 → tree다.

4. Greedy 예제 — 가중치 순서대로

빈 그래프에서 시작해 edge를 가중치 오름차순으로 본다. 추가해도 cycle이 생기지 않으면 넣는다:

  • Weight 1 ~ 5: 모두 추가 (cycle 없음).
  • Weight 6: cycle이 생기므로 skip.
  • Weight 7 (5개): 모두 추가. Weight 9: v–w가 이미 연결되어 있으면 skip (cycle), 아니면 추가.
  • Weight 12: skip.

결과가 MST다. 이를 정식화하면 Kruskal's algorithm.

5. Kruskal's algorithm

Kruskal(G):                          # undirected, edge weights
    1. edge를 가중치 오름차순으로 정렬 (mergesort 등)
    2. X ← ∅                          # 현재까지 MST에 넣은 edge 집합
    3. 정렬된 순서대로 각 edge e = (v, w)에 대해:
         e를 X에 넣어도 cycle이 생기지 않으면 → X ← X ∪ {e}
    4. return X

"Cycle이 생기는가"의 판정: X의 subgraph에서 v와 w가 같은 component에 있으면 이미 v–w path가 존재 → e를 추가하면 cycle. 다르면 추가.

6. 런타임 분석 — O(m log n)

  • Step 1 (정렬): O(m log n) (= O(m log m)).
  • Step 3 (검사+병합): Union-Find 자료구조로 연산당 O(log n). c(v), c(w) 조회 + (추가 시) merge. 최대 m회 연산 → O(m log n).
총합 O(m log n). 이 강의의 초점은 자료구조가 아니라 정확성 증명이다.

7. 정확성 아이디어 — induction

Induction 가정: 현재 X는 correct so far = 어떤 MST T의 subgraph (X ⊆ T). 이제 edge e를 추가하려 한다 (v, w가 다른 component에 있어 cycle이 안 생김).

Claim: X ∪ {e}도 correct so far, 즉 어떤 MST T′의 subgraph다. (T′는 T와 다른 MST일 수 있다 — 특정 MST가 아니라 어떤 MST로 가는 중이면 된다.)

핵심 관찰: S = c(v) (v의 component)라 두면, X의 어떤 edge도 S와 S̄ 사이를 가로지르지 않는다 (component는 maximal이므로). 그런데 e는 S–S̄를 가로지르고, 정렬 순서상 e는 S–S̄를 가로지르는 최소 가중치 edge다. → 이것이 바로 cut property의 조건.

8. Cut 정의

Cut: 정점을 S와 S̄(여집합)으로 나누는 분할. cut(S, S̄) = 한쪽 끝은 S, 다른 쪽 끝은 S̄에 있는 edge들의 집합 (S–S̄를 "가로지르는" edge들).

Cut(S, S̄): S와 S̄ 사이를 가로지르는 edge들의 집합 (빨간선).

9. Cut property (진술)

Cut property: 다음을 가정한다.

  • X는 correct so far (어떤 MST T의 subgraph).
  • X의 어떤 edge도 cut(S, S̄)를 가로지르지 않는다.
  • e*는 cut(S, S̄)를 가로지르는 최소 가중치 edge (동점자 중 아무거나).

결론: X ∪ {e*}도 correct so far — 즉 어떤 MST T′의 subgraph다.

직관: e*를 포함하지 않는 tree T가 있으면, e*를 넣고 cycle에서 한 edge를 빼면 weight가 늘지 않는 새 tree를 만들 수 있다 (아래 증명).

10. Cut property → Kruskal's

Kruskal's에서 e* = (v, w)를 추가할 때: S = c(v) (v의 component). Component가 maximal이므로 X의 edge 중 S–S̄를 가로지르는 것은 없다. 정렬 순서상 e*는 S–S̄를 가로지르는 최소 가중치 edge다. → Cut property의 가정을 만족 → X ∪ {e*}는 여전히 correct so far. ∎

11. 증명 — T′ 구성

고정: G, X ⊆ T (T는 MST), cut(S, S̄) (X의 edge는 안 가로지름), 최소 가중치 cut edge e* (양 끝점 a, b). 목표: X ∪ {e*} ⊆ T′인 MST T′를 구성.

  • 쉬운 경우: e* ∈ T이면 T′ = T. 끝.
  • 어려운 경우: e* ∉ T. T ∪ {e*}는 cycle C를 만든다 (tree에 edge를 하나 더하면 cycle — T 안에 a–b path가 있으니까).

T는 connected이므로 a–b path는 S–S̄를 최소 한 번은 가로지른다. 그 가로지르는 edge 중 T에 속한 것을 e′이라 하자 (e*도 cut을 가로지르므로 e′는 cycle C 위에 있다). T′ = T ∪ {e*} − {e′} 로 둔다.

12. T′는 tree다

판정법: connected + edge 정확히 n−1개.

  • Edge 수: T가 n−1개, 하나 넣고 하나 뺐으므로 그대로 n−1개. ✓
  • Connected: 임의의 y, z에 대해 T 안의 path P를 취한다. P가 e′를 쓰지 않으면 그대로 T′의 path. e′ = (c, d)를 쓰면, cycle C에서 e′를 뺀 나머지 (= T′에 있는 c–d path P′)로 e′를 대체한다. (Walk가 되지만 backtracking을 잘라 path로 만들 수 있으므로 연결됨.) ✓

사실 cycle의 어떤 edge를 빼도 tree가 된다 — 이게 증명의 핵심 아이디어 중 하나.

13. T′는 MST다

  • weight(T′) = weight(T) + w(e*) − w(e′).
  • e*는 cut의 최소 가중치 edge이고 e′도 cut을 가로지르므로 w(e*) ≤ w(e′). → weight(T′) ≤ weight(T). T가 MST이므로 weight(T′) = weight(T). T′도 MST. ∎

기억할 두 가지:

  • 진술: cut을 가로지르는 최소 가중치 edge는 어떤 MST에 속한다.
  • 증명 아이디어: tree에 edge를 넣으면 cycle이 생기고, cycle에서 아무 edge나 빼면 새 tree가 된다.

14. Prim's algorithm

Prim's도 cut property로 정확성을 증명할 수 있다 (Dijkstra's와 비슷한 형태의 MST 알고리즘). Cut property를 이해했는지 확인하는 연습으로 Prim's의 정확성을 직접 증명해보자.

체크리스트

  • Kruskal's 의사코드를 쓰고 O(m log n)을 설명할 수 있다 (정렬 + union-find).
  • Cut과 cut(S, S̄)의 정의를 말할 수 있다.
  • Cut property를 정확히 진술할 수 있다 (3가지 가정 + 결론).
  • Cut property → Kruskal's 연결 (S = c(v))을 설명할 수 있다.
  • T′ = T ∪ {e*} − {e′} 구성을 그릴 수 있다.
  • T′가 tree인 이유 (connected + n−1 edges)를 증명할 수 있다.
  • T′가 MST인 이유 (w(e*) ≤ w(e′))를 증명할 수 있다.
  • Prim's도 cut property로 증명할 수 있음을 안다.
