1. Max-flow with demands — feasible flow

A generalization of max-flow: every edge e carries a demand d(e) >= 0. Goal: find a feasible flow:

  • d(e) <= f(e) <= c(e) — flow at least the demand, at most the capacity.
  • Flow conservation — flow in = flow out at every internal vertex except s, t (as before).

Plan: 1) decide whether a feasible flow exists; 2) if so, augment it to maximum size.

2. Quiz — feasible flow example

Q. A directed graph shows demands (green) and capacities (red) on every edge. Write a valid flow meeting demand and capacity constraints for edges sa, sb, sc, ad, ae, be, cf, dc, dt, ed, fe, ft.

How to check: every edge must satisfy d(e) <= f(e) <= c(e), and flow in = flow out at every vertex except s and t. (E.g. if (s,a) reads "at least 2, at most 8", then f(sa) must be between 2 and 8.)

3. Reduction overview — max-flow as a black box

Reduce the feasible-flow problem to the max-flow problem, using the max-flow algorithm as a black box (a subroutine whose insides we don't touch):

  1. Transform the feasible-flow input (G, c(e), d(e)) via function g into a max-flow input (G', c'(e)). Demands disappear, encoded into the graph and capacities.
  2. Run black-box max-flow on G' to get a solution f'.
  3. Transform f' via function h into a feasible flow f for the original problem.

4. Reduction — vertices (add s', t')

New directed graph G': keep the original graph G, add a new source s' and a new sink t'. The original s and t become internal vertices.

5. Reduction — old edges (capacity shift)

Keep G's edges in G' but shift capacities down by the demand:

c'(e) = c(e) - d(e)

Idea: flow 0 in G' corresponds to flow d(e) in G; i.e. f' is f shifted down by d. Non-negative flow in G' means demands met in G; respecting c'(e) in G' means respecting c(e) in G.

Example (4 vertices): (s,a) with (d=3, c=10) becomes c'=7. (a,t): (7,8) -> c'=1. (a,b): (1,5) -> c'=4. (b,t): (2,6) -> c'=4. (s,b): (d=4, c=9) -> c'=5.

6. Reduction — new edges (offsetting the imbalance)

Shifting alone breaks validity: zero flow is valid in G', but the corresponding flow in G (d(e) on each edge) has, e.g. at vertex a, flow in 3 vs flow out 8 — not valid. Offset this imbalance with:

  • For each vertex v, edge s' -> v with capacity = total demand into v (d_in(v) = sum over u of d(uv)).
  • For each vertex v, edge v -> t' with capacity = total demand out of v (d_out(v) = sum over w of d(vw)).

Example: s'->a: 3, s'->t: 7+2=9, s'->b: 5, s'->s: 0; s->t': 3+4=7, a->t': 1+7=8, t->t': 0, b->t': 2.

G' construction: old edges with c' = c − d, s'->v (d_in), v->t' (d_out), t->s (infinite).

7. Reduction — the t -> s edge (infinite)

The original s and t are internal vertices of G', so flow in must equal flow out for both. In the original graph there was no flow into s and no flow out of t. Fix: flow out of s equals flow into t, so add edge t -> s with infinite capacity, routing t's outflow back to s. This completes the construction of G'.

8. Saturating flows — D

D = total demand of the original network = sum over e of d(e) = sum over v of d_in(v) = sum over v of d_out(v).

  • Total capacity out of s' = sum over v of d_in(v) = D.
  • Total capacity into t' = sum over v of d_out(v) = D.
  • Hence any flow f' in G' has |f'| <= D.
Saturating flow: a flow with |f'| = D — every edge out of s' and every edge into t' is fully saturated. This is a maximum flow.
Lemma: G has a feasible flow iff G' has a saturating flow.

9. Proof (forward) — saturating implies feasible

From a saturating flow f', build f(e) = f'(e) + d(e) (undo the shift).

  • Demand: f'(e) >= 0 implies f(e) >= d(e). Done.
  • Capacity: f'(e) <= c'(e) = c(e) - d(e) implies f(e) <= c(e). Done.
  • Conservation: f' is valid, so f'_in(v) = f'_out(v). Saturation gives f'(s'->v) = d_in(v). Algebra: f'_in(v) = d_in(v) + sum over u of (f(uv) - d(uv)) = f_in(v). Similarly f'_out(v) = f_out(v). Hence f_in(v) = f_out(v). Done.

Key: setting s'->v capacity to d_in(v) exactly cancels the shift's imbalance.

10. Proof (reverse) — feasible implies saturating

From a feasible flow f, build f':

  • Old edges: f'(e) = f(e) - d(e) (shift down by demand).
  • s'->v: fully saturated (d_in(v)); v->t': fully saturated (d_out(v)) — aiming for saturation.
  • t->s: flow set to |f| (the size of f).
  • Non-negative: f(e) >= d(e) gives f'(e) >= 0. Done.
  • Capacity: f(e) <= c(e) gives f'(e) <= c(e) - d(e) = c'(e). Done.
  • Conservation: f'_in(v) = d_in(v) + sum over u of (f(uv) - d(uv)) = f_in(v); f'_out(v) = f_out(v). Since f is valid, f' is valid at every vertex except s', t' (including the original s and t). Done.

All s'->v and v->t' edges saturated gives |f'| = D — saturating.

11. Maximum feasible flow — modified residual graph

Once a feasible flow f is found, augment it Ford-Fulkerson/Edmonds-Karp style to maximum size. Two differences:

  1. Start from the feasible flow f, not the zero flow.
  2. Reverse-edge capacities differ: flow can never drop below demand, so the reducible amount is f(e) - d(e).

Modified residual graph (current flow f):

  • Forward edge v->w: capacity c(e) - f(e) (leftover, as before).
  • Reverse edge v->w (when w->v carries flow): capacity f(e) - d(e) (can only decrease down to the demand). Previously this was f(e).

Repeat s–t augmentations until no path remains — a maximum-size feasible flow.

12. Quiz — reduction example

Q. Given an input graph G for feasible flow and the reduced graph G' (the purple t->s edge has infinite capacity, marked N in the figure), compute the capacities in G': (s',a), (s',b), (s',c), (s',d), (s',e), (s',f), (s',t), (a,t'), (b,t'), (c,t'), (d,t'), (e,t'), (f,t'). Then: does G' have a saturating flow? Does the original G have a feasible flow?

Method:

  • (s',v) = d_in(v): sum of demands on edges into v in G.
  • (v,t') = d_out(v): sum of demands on edges out of v in G.
  • Old edge (u,v) capacity becomes c - d.
  • D = sum of d(e). Run max-flow; if |f'| = D it is saturating, and the lemma gives a feasible flow in G.

Glossary

TermMeaning
Demand d(e)Minimum flow required on edge e. Non-negative.
Feasible flowA valid flow with d(e) <= f(e) <= c(e). Existence is the first question.
ReductionTransforming one problem into another; here feasible flow to max-flow.
Black boxA subroutine used by input/output only. How the max-flow algorithm is used.
Shifted capacity c'(e)c(e) - d(e). Capacity of old edges in G'. Relation: f' = f - d.
d_in(v) / d_out(v)Total demand into / out of vertex v. Capacities of s'->v and v->t'.
Circulation edge (t -> s)Infinite-capacity edge making s and t internal vertices.
D (total demand)Sum over e of d(e). Total capacity out of s' = into t' = D.
Saturating flowFlow with |f'| = D. All s'-outgoing and t'-incoming edges saturated.
Residual graph (modified)Forward: c - f; reverse: f - d. Flow can never drop below demand.
Augmenting pathAn s–t path in the residual graph; augmenting along it grows the flow.
