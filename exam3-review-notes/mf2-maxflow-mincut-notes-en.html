1. Two goals of this lecture

  1. Prove the Max-flow = Min-cut theorem.
  2. Prove correctness of Ford-Fulkerson — correctness of Edmonds-Karp follows as a byproduct.

In MF1 we analyzed FF's O(mC) runtime but never proved its output is really a max-flow. This lecture closes that gap.

2. Recap + quiz — verifying max-flow

FF's stopping condition

FF stops when the residual graph Gf* of the current flow f* has no augmenting path (s → t path). Key lemma: a flow with no augmenting path in its residual graph is a max-flow. (Proved in this lecture.)

Q. Given a flow network and a flow f, how long does it take to check whether f is a max-flow? Answer in big-O in terms of n = |V|, m = |E|.

Answer: O(n + m) — linear time.

  • By the lemma: build f's residual graph in O(n+m), run DFS from s to test t-reachability in O(n+m).
  • t unreachable → no augmenting path → f is a max-flow (Yes).
  • t reachable → augment along that path for a larger flow → f is not a max-flow (No).

Exam point: "is it a max-flow?" = residual graph + DFS reachability, O(n+m) — the same cost as one FF round.

3. Min-cut problem — st-cut and capacity

  • A cut partitions vertices into two sets: left L, right R.
  • An st-cut has s ∈ L, t ∈ R (separates s from t).
  • Capacity of a cut: sum of capacities of edges going L → R. Edges R → L are ignored (direction matters in a directed graph).

Example: L = {s, a, b, f}, R = {c, d, e, t} (L need not be connected). Six L → R edges: s→c, a→d, a→e, b→e, f→e, f→t. Capacity = 8 + 2 + 2 + 5 + 7 + 3 = 27. Edges like c → f (R → L) don't count.

st-cut example. Red edges (L→R) sum to 8+2+2+5+7+3 = 27. Dashed c→f is R→L, excluded.

4. Min st-cut — formulation

Input: flow network (directed graph + s, t + positive capacities).

Output: the st-cut (L, R) (s ∈ L, t ∈ R) of minimum capacity. Capacity = sum of L → R edge capacities (R → L ignored).

Example: the cut with R = {t} and L = everything else has capacity 12 (the two edges into t). This is a min st-cut. How do we know it's minimum? → By the Max-flow = Min-cut theorem: a flow of size 12 exists in this graph, so flow 12 = cut 12 forces both to be optimal.

5. Theorem — Max-Flow = Min st-Cut

Theorem. For any flow network, (max-flow size) = (min st-cut capacity).

Notation note: we say "st-cut" to stress separating s from t. The general min-cut problem need not separate any s, t — hence "min st-cut" is distinguished. Likewise max-flow is really "max st-flow".

Proof strategy: prove both inequalities.

  • ① max-flow ≤ min st-cut capacity
  • ② max-flow ≥ min st-cut capacity

6. Proof ① — max-flow ≤ min-cut

Instead of ① directly, prove an easier statement:

Sufficient: if for any flow f and any st-cut (L, R), size(f) ≤ cap(L, R), then ① follows.

Why? Maximizing over f (a max-flow is still a flow) turns the left side into the max-flow; the right side holds for any cut, so we may take the minimum cut.

Intuition: flow from s to t must exit L at some point, and the only exits are the L → R edges. If those total 27, the flow can't exceed 27.

Key claim

Claim: size(f) = fout(L) − fin(L). (flow leaving L minus flow entering L)

Given the claim, ① is immediate: size(f) = fout(L) − fin(L) ≤ fout(L) ≤ cap(L,R). (Dropping the second term only increases; outgoing flow can't exceed per-edge capacities.)

7. Proof of claim — size(f) = fout(L) − fin(L)

  1. fout(L): sum of flows on edges with tail outside L, head inside L. fin(L): the reverse.
  2. Add and subtract the internal edges (both ends in L) — value unchanged.
  3. Positive terms combine into: total flow out of each vertex v ∈ L. Negative terms combine into: total flow into each vertex v ∈ L.
  4. Separate s: flow into s is 0, leaving flow out of s = size(f).
  5. Every other v ∈ L − {s} has out = in by flow conservation → those terms sum to 0.

Hence size(f) = fout(L) − fin(L). ∎

This claim is reused in proof ②.

8. Proof ② — max-flow ≥ min-cut (constructing the cut)

Take f*, the flow output by Ford-Fulkerson. FF stopped with no augmenting path, so Gf* has no s → t path.

Cut construction: L = vertices reachable from s in Gf*, R = the rest. t is unreachable, so t ∈ R; s ∈ L. Hence (L, R) is a valid st-cut.

We now show this cut's capacity equals size(f*) — then ② follows (see §10).

9. Properties of the constructed cut

Example: L = {s, a, b, d, e} (reachable from s in the residual graph), R = {c, f, t}.

L → R edges are fully saturated

  • Example: d → t, d → c, s → c.
  • Why: if v → w (v ∈ L, w ∈ R) appeared in the residual graph, w would be reachable and belong to L — contradiction. So no forward edge in the residual means flow = capacity.
  • ∴ fout(L) = cap(L, R).

R → L edges carry zero flow

  • Example: f → e is the only R → L edge.
  • Why: if z → y (z ∈ R, y ∈ L) carried positive flow, the backward edge y → z would be in the residual graph, and since y ∈ L, z would be reachable → z ∈ L, contradiction. Hence zero flow.
  • ∴ fin(L) = 0.

L = vertices reachable from s in the residual graph. Red L→R edges are fully saturated; dashed f→e carries zero flow. Hence size(f*) = cap(L,R).

Plugging into the claim (§7): size(f*) = fout(L) − fin(L) = cap(L,R) − 0 = cap(L,R). ∎

10. Completing the theorem — byproducts

Finishing ②

We proved size(f*) = cap(L,R). Then:

  • max-flow ≥ size(f*) (the max is at least this particular flow).
  • cap(L,R) ≥ min st-cut capacity (this particular cut is at least the min).
  • ∴ max-flow ≥ min st-cut capacity. With ①, equality. ∎

Byproducts

  1. Lemma proved: for f* with no augmenting path we built a cut with size(f*) = cap(L,R); equality forces both optimal — so f* is a max-flow. (§2's lemma done.)
  2. Ford-Fulkerson is correct: FF stops exactly when there's no augmenting path, so its output is a max-flow. Edmonds-Karp stops under the same condition → correct too.
  3. Min-cut construction: given a max-flow f*, L = {reachable from s in the residual graph} yields a min st-cut. (Used in the upcoming image segmentation application.)
# Verifying max-flow (the quiz answer, in code)
def is_max_flow(G, s, t, f):
    Gf = build_residual(G, f)   # O(n + m)
    return not dfs_reaches(Gf, s, t)  # O(n + m) → O(n + m) total

# Min st-cut from a max-flow f*
def min_st_cut(G, s, f_star):
    Gf = build_residual(G, f_star)
    L = {v : reachable from s in Gf}  # DFS/BFS
    R = V - L
    return (L, R)  # cap(L, R) == size(f*)
