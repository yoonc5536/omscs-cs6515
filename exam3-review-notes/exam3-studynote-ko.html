1단계 · 그래프 코어 — DFS · Topological Sort · SCC · 2-SAT 55분

모든 reduction의 토대. 상세는 GR1 노트 · GR2 노트. 여기서는 시험에 직접 쓰이는 것만 압축한다.

DFS와 pre/post

DFS(G):
  for all v in V: visited[v] = false
  clock = 1
  for all v in V: if not visited[v]: Explore(v)

Explore(v):
  visited[v] = true;  pre[v] = clock;  clock++
  for each edge (v, u) in E:
    if not visited[u]: prev[u] = v; Explore(u)
  post[v] = clock;  clock++
  • 간선 4종: tree / forward / back / cross. postorder를 키우는 건 사실상 back edge뿐.
  • Cycle ⟺ back edge 존재. 이 한 줄이 여러 정당화에 재사용된다.
  • Topological sort = postorder 내림차순. post 값 범위가 1..2n이라 counting sort로 O(n+m) 유지.

SCC — Kosaraju 4단계

① GR 구성모든 간선 뒤집기 O(n+m)
→
② GR에서 DFSpostorder 기록
→
③ G에서 DFSpost 높은 정점부터, 도달 범위가 한 SCC
→
④ MetagraphSCC를 노드로 압축하면 DAG
  • Key fact: postorder가 가장 큰 정점은 source SCC에 있다 (G 기준). 그래서 뒤집은 그래프에서 먼저 구한 순서로 원본을 처리하면 sink SCC부터 떨어진다.
  • 특정 정점의 SCC 찾기: 전체를 스캔하지 말고 ccnum[v]를 O(1)에 읽는다 (3.15 (b)의 핵심).
  • 패턴 — 강연결 판정 (3.15): metagraph 정점이 1개면 전체가 한 SCC.
  • 패턴 — mother vertex (3.22): 모든 정점에 도달 가능한 정점 후보는 sink SCC 쪽에서 찾고, 후보에서 DFS 한 번으로 검증.

Metagraph는 항상 DAG → source/sink SCC 개념, topo 순서가 그대로 먹힌다.

2-SAT (10분만)

  • Clause (α ∨ β) → 간선 2개: ᾱ → β, β̄ → α. 변수 x와 ¬x 각각 정점 → 총 2n 정점, 2m 간선.
  • x와 ¬x가 같은 SCC ⟺ unsatisfiable. 아니면 satisfiable.
  • 할당 규칙: sink SCC의 literal = True, 그 complement (source 쪽) = False.

2단계 · Shortest Paths — 고르는 기준이 전부다 45분

상세는 DP3 강의 가이드. 알고리즘 내부보다 선택 기준 + 출력 읽는 법 + 트릭 2개가 시험용이다.

상황선택Runtime비고
가중치 전부 ≥ 0, 한 출발점DijkstraO((n+m) log n)BFS + min-heap 구조. 음수 간선 있으면 사용 불가
음수 간선 가능Bellman-FordO(nm)iter[k][v] = 간선 ≤ k개 쓰는 최단 거리. k = n−1에서 확정
전쌍 (all pairs)Floyd-WarshallO(n³)iter[k][i][j] = 중간 정점을 {1..k}로 제한한 최단 거리
무가중BFSO(n+m)dist[]가 곧 간선 수
  • Negative cycle 검출: BF에서 iter[n−1][v]와 iter[n][v]를 비교 — n번째 반복에서 또 줄면 negative cycle에 닿는 정점. (기출 P5/통화 문제 4.21의 핵심 판정)
  • 경로 복원: dist[]가 아니라 prev[]를 t에서 거꾸로 따라간다. 트리에서는 s–t 경로가 유일하다는 것도 자주 쓰인다.

트릭 ① Reverse graph — "v0를 지나는 최단 경로" (4.14)

모든 정점 → v0 거리는, 간선을 뒤집은 GR에서 v0 출발 Dijkstra 한 번으로 구한다. 그다음 distR[u] + dist[w]가 u ⇝ v0 ⇝ w 최단 거리. "to X" 문제를 "from X"로 바꾸는 변환은 시험 단골이다.

트릭 ② 가중치 인코딩 — 사전식 최적화 (기출 P1)

빨간 간선 최소, 그다음 파란 간선 최소 → 가중치를 red = m+1, blue = 1로 두면 경로 가중치 = (m+1)·(#red) + (#blue). #blue ≤ m < m+1이라 Dijkstra 한 번이 사전식 최적을 그대로 준다. "1순위·2순위" 조건이 보이면 base-(m+1) 인코딩을 떠올려라.

트릭 ③ 로그 변환 — 곱셈을 덧셈으로 (4.21 통화 거래)

환율 곱이 최대인 경로 = −log(rate)를 간선 비용으로 두면 최단 경로 문제가 되고, 이익 나는 사이클 = negative cycle (Bellman-Ford로 검출).

3단계 · MST — Cut Property 하나면 된다 40분

상세는 GR3 노트.

⭐ Cut Property: 어떤 cut (S, V∖S)에 대해, 그 cut을 가로지르는 최소 가중치 간선은 어떤 MST에 반드시 포함된다. Kruskal의 정당화 (S = 한쪽 컴포넌트), Prim의 정당화 (S = 지금까지 키운 트리)가 전부 이 한 문장에서 나온다.
Kruskal(G):
  sort edges by weight (increasing)
  T = empty;  initialize union-find (each vertex its own set)
  for each edge (u, v) in sorted order:
    if find(u) != find(v): add (u, v) to T; union(u, v)
  return T          // O(m log n)
  • 트리 사실: 간선 n−1개 · connected + 간선 n−1개 = 트리 · 트리에서는 m = n−1이라 runtime이 O(n)으로 떨어질 때가 있다.
  • Cycle Property (5.22): 어떤 cycle의 가장 무거운 간선은 어떤 MST에서도 제외할 수 있다 → reverse-delete 알고리즘의 근거. 반대로, 유일하게 가장 무거운 간선이 MST에 있으면 그 간선은 bridge여야 한다.
  • Maximum spanning tree (5.7): 가중치 부호를 뒤집거나 Kruskal을 내림차순으로 — 같은 뼈대 재사용.
  • 5.9 판정 요약: (a) F — 간선이 하나뿐인 정점 반례 / (b) T — Kruskal 처리 순서 / (c) T — 최소 가중치 간선은 어떤 MST의 후보 / (d) T — Cut Property.

트릭 — Big-M 가중치 (기출 P3: U를 전부 leaf로)

U에 닿는 간선마다 M = 1 + Σ|w(e)|를 더한 w′로 Kruskal을 돌리면, MST는 U-간선 개수를 먼저 최소화한다. "특정 간선을 피하라/강제하라"는 조건은 대부분 이런 가중치 조작으로 reduction 된다.

4단계 · Max Flow — Residual Graph가 전부다 50분

상세는 MF1 · MF2 · MF5 노트.

기본기 3개

  • Flow 조건: 0 ≤ f(e) ≤ c(e) (capacity) · s, t 외 모든 정점에서 inflow = outflow (conservation). Flow 값 = s에서 나가는 순유량.
  • Residual graph Gf: 간선 (u,v)에 대해 forward 잔여 = c − f (더 보낼 여유), backward 간선 = f (취소 가능량).
  • 판정: Gf에 s–t 경로 (augmenting path)가 없음 ⟺ max flow.

기출형 수치: c=10, f=7인 간선의 residual은 forward 3 / backward 7. 포화된 간선도 backward는 살아 있다 — 방향 감각이 Q5·Q10형 함정을 가른다.

Ford-Fulkerson(G, s, t):
  f = 0 flow
  build residual graph G_f
  while there is an s-t path P in G_f:
    augment f by the bottleneck capacity of P; update G_f
  return f            // O(mC) — C는 max flow 값; Edmonds-Karp(BFS 선택)는 O(nm^2)

Max-flow = Min-cut (MF2)

  • st-cut 용량: L→R 방향 간선의 원래 capacity 합만 센다 (R→L은 무시, flow와 무관).
  • 관계식: size(f) = fout(L) − fin(L) ≤ cap(L, R). 등호가 성립하면 f는 max, cut은 min (weak duality).
  • Min-cut 구성법: max flow의 residual graph에서 s가 도달 가능한 집합 L — 그게 min cut이다. 시험에서 "min cut을 구하라"면 이 한 줄.
  • 주의 (함정): min cut에서는 L→R 간선이 포화되지만, R→L 간선은 flow가 0일 뿐 포화가 아니다. size(f) = cap(L,R)라는 등식도 일반적으로는 거짓 (반례: 역방향 flow).

패턴 2개

검증 패턴 (7.19)
① capacity·conservation 검사 O(n+m) → ② residual에서 BFS로 t 도달 가능성 확인. augmenting path 없음 = max. "주어진 해를 검증하라"는 선형 시간에 끝난다.
증분 패턴 (기출 P2)
용량 1짜리 간선 1개 추가 → 기존 max flow를 버리지 말고 residual에서 augmenting path 최대 1번만 찾는다. 증가량은 최대 1. 전체 O(n+m).
Demands 확장 (MF5, 10분만): 하한 d(e) ≤ f(e) ≤ c(e)인 feasible flow는 그래프 변환으로 max flow black box에 태운다 — 원 간선 용량을 c−d로, 수요 불균형을 새 source/sink s′·t′로 연결, t→s 무한 용량 간선 추가, D = Σd(e)를 포화시키면 feasible. "변형된 flow 문제 = 그래프를 고쳐서 black box"라는 감각만 가져가면 된다.
