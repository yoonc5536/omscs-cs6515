Q1. Capacity를 전부 1씩 늘리면 max flow는 여전히 valid한가?

Flow network G = (V, E), source s, sink t, capacity c(e). f가 max s-t flow다. 모든 edge의 capacity를 1씩 증가시킨다. True or False: f는 새 네트워크에서 valid한 flow다.

(A) True   (B) False

정답: (A) True.

Valid flow의 두 조건을 확인:

  • Capacity constraint: 0 ≤ f(e) ≤ c(e) < c(e)+1 이므로 그대로 만족.
  • Flow conservation: f(e) 자체는 안 바뀌었으므로 그대로 만족.

핵심: validity는 flow 값에 대한 조건이지 capacity에 대한 게 아니다. Capacity가 커져도 기존 flow는 그대로 valid.

Q2. Capacity를 전부 1씩 늘리면 max flow는 여전히 max인가?

Q1과 같은 설정. True or False: f는 새 네트워크에서도 max s-t flow다.

(A) True   (B) False

정답: (B) False.

반례: s → t 단일 edge, capacity 1. Max flow = 1. Capacity를 2로 늘리면 새 max flow는 2인데, 기존 f의 값은 1 → 더 이상 max가 아니다.

Capacity +1 후 기존 flow(값 1)는 valid하지만(Q1) max는 아니다(Q2).

교훈: valid ≠ max. Q1과 Q2는 한 쌍으로 이 구분을 묻는다.

Q3. Unit capacity에서 max flow 값과 edge-disjoint path

Directed flow network, 모든 edge의 capacity c(e) = 1. Max s-t flow 값이 k다. 옳은 것은?

(A) G는 s-t edge-disjoint path를 최대 k개 포함한다.   (B) G는 s-t edge-disjoint path를 최소 k개 포함한다.
(C) G는 s-t edge-disjoint path를 정확히 k개 포함한다.   (D) None of the above.

정답: (C). Menger's theorem (edge 버전): unit capacity 네트워크에서 max flow 값 = edge-disjoint s-t path의 최대 개수.

  • ≥ k 방향: Integral flow theorem — 정수 capacity면 정수 max flow가 존재. 값을 k인 정수 flow를 flow decomposition하면 1씩 흐르는 k개의 s-t path가 나오고, unit capacity라 서로 edge를 공유할 수 없다.
  • ≤ k 방향: k+1개의 edge-disjoint path가 있으면 각각 1씩 흘려보내 flow k+1을 만들 수 있어 max flow = k에 모순.

참고: 엄밀히는 (A)와 (B)도 참인 약한 명제다. (C)가 정리 전체를 담은 intended answer.

Q4. Ford-Fulkerson의 최대 iteration 횟수

정수 capacity 네트워크에서 Ford-Fulkerson을 돌린다. Max flow 값이 C다. Main loop의 최대 iteration 횟수는?

(A) O(|V|·|E|)   (B) O(|E|·C)   (C) C   (D) |E|

정답: (C) C.

  • Capacity가 정수면 각 augmenting path의 bottleneck도 정수이므로, 한 번의 augmentation마다 flow가 최소 1 증가.
  • Flow 값은 C를 넘을 수 없으므로 iteration은 최대 C번.

주의: (B) O(|E|·C)는 전체 런타임이다 (한 iteration당 residual graph 탐색 O(|E|)). "Iteration 횟수"를 물었으므로 (C).

Q5. 0이 아닌 flow에서 시작한 Ford-Fulkerson

정수 capacity 네트워크, f는 valid한 정수 s-t flow. Ford-Fulkerson을 0이 아닌 f에서 시작한다. True or False: 알고리즘은 종료하고 max s-t flow를 찾는다.

(A) True   (B) False

정답: (A) True.

  • Residual graph Gf는 어떤 feasible flow에서든 만들 수 있다 (0일 필요 없음).
  • Capacity와 f가 정수면 residual capacity도 정수 → 매 augmentation마다 flow가 최소 1 증가 → 유한 번에 종료.
  • 정확성 (augmenting path가 없으면 max flow)은 시작 flow와 무관하게 성립.

MF5의 max feasible flow도 같은 아이디어: feasible flow에서 시작해 수정된 residual graph로 augment.

Q6. v(f) = C(A,B)이면?

Cut (A, B) (s ∈ A, t ∈ B), flow f에 대해 v(f) = C(A, B)다. 반드시 참인 것은?

(A) f는 maximum flow다.   (B) (A, B)는 minimum cut이다.
(C) Both A and B.   (D) Neither A nor B.

정답: (C) Both A and B.

Weak duality: 임의의 flow f′와 cut (A′, B′)에 대해 v(f′) ≤ C(A′, B′).

  • f보다 큰 flow는 존재할 수 없다 (모든 flow ≤ C(A,B) = v(f)) → f는 max flow.
  • (A,B)보다 작은 cut은 존재할 수 없다 (모든 cut ≥ v(f) = C(A,B)) → (A,B)는 min cut.

Max-flow min-cut 정리의 증명 핵심 아이디어: 같은 값을 달성하는 flow–cut 쌍이 서로를 최적이라 증명한다.

Q7. Capacity를 전부 k배하면 max flow는?

정수 capacity, max flow 값 F. 모든 edge의 capacity에 양의 정수 k를 곱하면 새 max flow 값은?

(A) F + k   (B) k·F   (C) Fk   (D) F

정답: (B) k·F.

  • ≥ kF: 원래 max flow f*에 k를 곱한 k·f*는 새 네트워크의 feasible flow (값 kF).
  • ≤ kF: 새 네트워크의 임의 flow g를 k로 나누면 원래 네트워크의 feasible flow (값 v(g)/k ≤ F) → v(g) ≤ kF.

Capacity 제약이 선형이라 스케일이 그대로 전달된다.

Q8. Flow가 0인 edge를 제거하면 max flow가 바뀌나?

f는 maximum flow, edge e = (u,v)에서 f(e) = 0이다. e를 제거하면 max flow 값이 바뀌는가?

(A) 항상 감소한다.   (B) 절대 바뀌지 않는다.
(C) e가 minimum cut에 속하는지에 달렸다.   (D) None of the above.

정답: (B) 절대 바뀌지 않는다.

  • f(e) = 0이므로 f는 G − {e}에서도 feasible, 값 v(f) 그대로 → 새 max flow ≥ v(f).
  • Edge 제거는 max flow를 늘릴 수 없으므로 새 max flow ≤ v(f).
  • ∴ 새 max flow = v(f). 그대로.

함정 (C): e가 min cut에 속해도 f(e) = 0이면 그 cut의 capacity에 기여하지 않으므로 제거해도 min cut 값은 그대로다.

Q9. Max flow의 residual graph는 DAG인가?

f는 maximum flow다. Residual graph Gf는 반드시 DAG인가?

(A) Yes   (B) No

정답: (B) No.

반례: 0 < f(e) < c(e)인 edge e = (u,v)가 있으면, residual graph에 forward edge (u,v)와 backward edge (v,u)가 둘 다 들어간다 → 2-cycle u → v → u. 따라서 DAG가 아니다.

0 < f(e) < c(e) → residual graph에 양방향 edge → cycle.

참고: max flow의 residual graph에는 s–t path가 없다는 것만 보장된다 (그게 max flow의 정의). Cycle은 얼마든지 있을 수 있다.

Q10. Min cut은 언제 유지되는가?

(A, B)는 minimum cut. Edge e ∈ E의 capacity를 1 증가시킨다. (A, B)가 minimum cut으로 남음이 보장되는 조건은?

(A) e ∈ A×B   (B) e ∉ A×B   (C) e ∈ B×A   (D) Always

정답: (B) e ∉ A×B.

  • Cut capacity C(A,B) = Σe ∈ A×B c(e). e ∉ A×B이면 C(A,B) 불변.
  • 다른 모든 cut의 capacity는 그대로거나 증가 (감소 불가).
  • ∴ (A, B)는 여전히 minimum.

참고: (C) e ∈ B×A도 충분조건이다 (B→A edge는 cut capacity에 안 들어가므로). 하지만 (B)가 이를 포함한 가장 일반적인 조건이라 intended answer.

체크리스트

  • Valid flow의 두 조건 (capacity, conservation)을 말할 수 있다.
  • Valid ≠ max를 반례로 설명할 수 있다 (Q1/Q2 쌍).
  • Menger's theorem (edge 버전)을 진술하고 양방향을 증명할 수 있다.
  • Ford-Fulkerson의 iteration bound C와 runtime O(mC)를 구분한다.
  • Residual graph가 임의의 feasible flow에서 정의됨을 안다.
  • Weak duality v(f) ≤ C(A,B)와 "같은 값이면 둘 다 최적"을 설명할 수 있다.
  • Capacity 스케일 시 max flow의 변화를 증명할 수 있다.
  • f(e) = 0인 edge 제거가 max flow에 영향 없음을 증명할 수 있다.
  • Residual graph의 2-cycle 예시를 그릴 수 있다.
  • Cut capacity 정의와 min cut 유지 조건을 설명할 수 있다.
