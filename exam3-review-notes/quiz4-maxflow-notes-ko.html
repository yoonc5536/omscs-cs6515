Q1. Residual network가 원래 네트워크와 같다면?

네트워크 G = (V, E), s, t ∈ V, capacity c(e), valid flow f가 있다. Residual network Gf가 주어진 네트워크 G와 같다. 반드시 참인 것은?

  1. The given flow f is equal to zero.
  2. The given flow f is a max flow.
  3. There is no path from s to t in Gf.
  4. There is no path from s to t in G.

정답: (a) f는 zero flow다.

  • Edge e = (u,v) ∈ E에 대해 residual forward edge의 capacity는 c(e) − f(e). Gf = G이려면 c(e) − f(e) = c(e) → 모든 edge에서 f(e) = 0.
  • f = 0이면 backward edge도 생기지 않으므로 residual network는 정확히 G와 일치. 정합.

(b): zero flow가 max인 것은 max flow 값이 0일 때뿐 — 보장 안 됨. (c)(d): Gf = G이므로 둘은 같은 말. G에 s–t path가 있어도 f = 0이면 Gf = G 성립.

Q2. size(f) = cap(L,R)이면? (복수 선택)

Valid flow f와 s–t를 분리하는 cut (L, R)이 있고, size(f) = cap(L,R)이다. 항상 참인 것을 모두 고르시오.

  1. The given flow f is a max flow.
  2. The given cut (L, R) is a min-cut.
  3. For every other valid flow f′, cap(L,R) ≥ size(f′).
  4. For every other cut (L′, R′), cap(L′,R′) ≥ size(f).

정답: (a), (b), (c), (d) 전부.

  • Weak duality: 임의의 flow f′와 임의의 cut에 대해 size(f′) ≤ cap. 이 전제 없이도 항상 성립 → (c), (d) 참.
  • 여기에 size(f) = cap(L,R)을 더하면 sandwich: 어떤 flow도 f를 못 넘고 → (a), 어떤 cut도 (L,R)보다 작아질 수 없고 → (b).

포인트: (c)(d)는 weak duality 그 자체라 "전제"가 필요 없는 문장. 이런 함정을 노린 복수선택이다.

Q3. 모든 capacity를 1씩 늘리면 새 max flow는?

Valid flow f (size(f) > 0)가 있다. 모든 edge의 capacity를 1씩 늘려 새 네트워크를 만들고, f′를 새 네트워크의 max flow라 하자. 반드시 참인 것은?

  1. size(f′) ≥ size(f) + cap(L,R), where (L,R) is a min cut.
  2. size(f′) ≥ size(f) + 1.
  3. size(f′) is never greater than size(f).
  4. size(f′) ≤ size(f) + 1.

정답: (b) size(f′) ≥ size(f) + 1.

증명. 새 네트워크의 max flow 값을 F′라 하자. 임의의 cut (L,R)에 대해 새 cut capacity는 capold(L,R) + n(L,R) (n = L→R edge 개수). 최소 cut (L*,R*)에서:

  • F′ = capold(L*,R*) + n(L*,R*) ≥ Fold + n(L*,R*).
  • size(f) > 0이므로 Fold > 0 → capold(L*,R*) > 0 → edge가 최소 1개 → n(L*,R*) ≥ 1.
  • ∴ F′ ≥ Fold + 1 ≥ size(f) + 1. (f는 새 네트워크에서도 valid하므로 F′ ≥ size(f)는 자명.)

(a) 반례: s→t 단일 edge, cap 5. size(f)=5, min cut cap=5인데 새 max는 6 < 5+5=10. (c) 반례: 같은 예에서 6 > 5. (d) 반례: s→t 병렬 2 edge (cap 1씩), f = max (값 2). 새 max = 4 > 2+1 = 3.

Q4. Residual에서 s로부터 도달 가능한 집합은 min cut인가?

f*는 valid max flow. S = { v ∈ V | residual network Gf*에서 s로부터 v로의 path가 존재 }. True or False: {S, V−S}는 minimum capacity의 st-cut이다.

Group of answer choices: True / False

정답: True.

Max-flow min-cut 증명의 표준 구성:

  • f*가 max이므로 t ∉ S (t가 reachable이면 augmenting path가 존재). 즉 (S, V−S)는 st-cut.
  • S→(V−S) edge는 전부 saturated (덜 찼으면 residual forward edge가 있어 도달 가능). (V−S)→S edge의 flow는 0 (양수면 residual backward edge가 있어 도달 가능).
  • ∴ cap(S, V−S) = f*out(S) − f*in(S) = size(f*) → min cut.

Q5. Min cut을 가로지르는 모든 edge가 saturated인가?

f*는 valid max flow, (L,R)은 minimum capacity의 st-cut. True or False: (L,R)의 서로 다른 쪽에 endpoint가 있는 모든 edge e에 대해 f(e) = c(e).

Group of answer choices: True / False

정답: False.

함정: "endpoints on different sides"는 R→L 방향 edge도 포함한다.

  • L→R edge: saturated 맞다 (f(e) = c(e)).
  • R→L edge: flow가 0이다. size(f) = fout(L) − fin(L) = cap(L,R)이려면 fin(L) = 0이어야.

반례: edge (s,t) cap 5, edge (t,s) cap 3. Min cut ({s},{t}) (cap 5). Edge (t,s)는 양쪽에 endpoint가 있지만 f(t,s) = 0 ≠ 3 = c.

R→L edge (t,s)는 min cut을 가로지르지만 flow가 0이다.

Q6. Flow에 대해 항상 참인 것은? (복수 선택)

Valid flow f가 있다. 항상 참인 것을 모두 고르시오.

  1. If f is a maximum flow, then every edge (s,v) is saturated OR every edge (w,t) is saturated.
  2. If there is no path from s to t in the residual network Gf, then f is a maximum flow.
  3. If f is a maximum flow, then every st-cut has capacity equal to the size of f.
  4. If f is a maximum flow, then the residual network Gf is never strongly connected.

정답: (b), (d).

  • (b) 참: augmenting path가 없으면 max flow — Ford-Fulkerson 정확성의 핵심.
  • (d) 참: max flow면 Gf에 s–t path가 없다. Strongly connected라면 s가 t에 도달해야 하므로 모순. 즉 Gf는 절대 strongly connected가 될 수 없다.

(a) 반례: s→a, s→b (cap 10씩), a→x, b→x (cap 3씩), x→t (cap 10). Max flow = 6인데 (s,a)는 3/10, (x,t)는 6/10으로 둘 다 unsaturated. (c): min cut만 size(f)와 같고, 다른 cut은 더 크다.

Q7. Residual network의 edge capacity 계산

Valid flow f. Edge e = (u,v), c(e) = 10, f(e) = 7. Edge (v,u)는 원래 네트워크에 없다. Residual network Gf에 대해 참인 것은?

  1. The residual network has an edge (u,v) with capacity 10, and edge (v,u) with capacity 7.
  2. The residual network has an edge (u,v) with capcity 3 and edge (v,u) with capcity 7.
  3. The residual network has only the edge (u,v) with capacity 7.
  4. The residual network has only the edge (u,v) with capcity 3.

정답: (b).

  • Forward edge (u,v): residual capacity = c − f = 10 − 7 = 3.
  • Backward edge (v,u): residual capacity = f = 7. (원래 네트워크에 없어도 residual에는 생긴다!)

공식 암기: forward는 남은 용량 c−f, backward는 되돌릴 수 있는 양 f.

Q8. Ford-Fulkerson에 대해 항상 참인 것은? (복수 선택)

Ford-Fulkerson Algorithm에 대해 항상 참인 것을 모두 고르시오.

  1. Every round increases the flow value by at least one.
  2. The algorithm terminates after at most |E| rounds.
  3. The runtime depends on the numerical value of the maximum flow.
  4. Choosing an arbitrary augmenting path always gives a polynomial-time algorithm in the input size.

정답: (a), (c). (정수 capacity 전제 — 강의의 표준 설정.)

  • (a) 참: 정수 capacity면 augmenting path의 bottleneck도 정수 → 매 round마다 flow가 최소 1 증가.
  • (c) 참: 런타임 O(m·C)는 max flow 값 C에 의존 → pseudo-polynomial.

(b) 반례: classic bad example (4개 정점, capacity C)에서 2C번의 round가 필요 — C가 크면 |E|를 초과. (d): arbitrary path 선택은 지수적일 수 있고, 무리수 capacity에서는 종료조차 안 됨. Polynomial이 되려면 Edmonds-Karp처럼 shortest path를 써야.

Q9. Max flow / min cut의 유일성 (복수 선택)

Positive integer capacities. 항상 참인 것을 모두 고르시오.

  1. All maximum flows have the same value.
  2. All minimum cuts have the same capacity.
  3. If the maximum flow is unique, then the minimum cut is also unique.
  4. If the minimum cut is unique, then the maximum flow is also unique.

정답: (a), (b).

  • (a)(b) 참: "maximum"/"minimum"의 정의상 값·capacity는 유일하다. (flow 자체가 유일하다는 뜻이 아님!)

(c) 반례: s→a (cap 2), a→t (cap 2), s→t (cap 1). Max flow는 유일하게 f = {s→a:2, a→t:2, s→t:1} (값 3). 하지만 min cut은 ({s},{a,t})와 ({s,a},{t}) 둘 다 capacity 3 → min cut은 유일하지 않음.

(d) 반례: s→a (1), s→b (1), a→t (5), b→t (5), a→b (1), b→a (1). Min cut은 ({s},{a,b,t}) 유일 (cap 2; 다른 cut은 ≥ 3). Max flow는 2가지: {a→t:1, b→t:1} 또는 {a→b:1, b→t:2} (둘 다 값 2). → min cut이 유일해도 max flow는 유일하지 않을 수 있다.

(d)의 반례: min cut은 유일하지만 max flow는 유일하지 않다.

Q10. L→R edge가 전부 saturated이면 max flow인가?

Valid flow f, st-cut (L,R). u ∈ L, v ∈ R인 모든 edge e = (u→v)에 대해 f(e) = c(e)이다. True or False: f is a maximum flow.

Group of answer choices: True / False

정답: False.

size(f) = fout(L) − fin(L) = cap(L,R) − fin(L). L→R이 saturated여도 R→L edge에 flow가 있으면 size(f) < cap(L,R) → max가 아닐 수 있다.

반례: (s,t) cap 5에 f = 5 (saturated ✓), (t,s) cap 3에 f = 2. Valid flow (s에서 net 3, t에서 net 3), 값 3. 하지만 max flow는 5 ((t,s)에 0을 흘리면). L→R edge는 전부 saturated인데도 f는 max가 아니다.

Q5와 같은 함정: R→L 방향을 잊지 말 것.

체크리스트

  • Residual edge capacity 공식 (forward c−f, backward f)을 말할 수 있다.
  • Weak duality size(f) ≤ cap(L′,R′)를 증명할 수 있다.
  • size(f) = cap(L,R) ⟹ f는 max, (L,R)은 min임을 sandwich로 설명할 수 있다.
  • Capacity +1 후 새 max flow가 최소 1 증가함을 증명할 수 있다.
  • Residual reachable set이 min cut임을 증명할 수 있다 (L→R saturated, R→L zero).
  • "Cut을 가로지르는 edge"가 양방향을 포함함을 주의한다 (Q5, Q10 함정).
  • size(f) = fout(L) − fin(L) 항등식을 쓸 수 있다.
  • Ford-Fulkerson의 pseudo-polynomial bound와 Edmonds-Karp의 차이를 안다.
  • Max flow 값의 유일성 vs flow 자체의 유일성을 구분한다 (Q9 반례 2개).
  • Gf에 s–t path가 없다는 것과 strongly connected의 관계를 안다.
