1. SAT 표기법

  • Boolean formula: 변수 x1 … xn은 True/False.
  • Literal: 변수의 positive/negative 형태 — 총 2n개 (x1, x̄1, x2, x̄2, …). x̄는 "x bar" 또는 "x complement".
  • ∧ = AND ("A처럼 생겼다"), ∨ = OR.
  • CNF (conjunctive normal form): clause들의 AND. 각 clause는 literal들의 OR. 예: (x̄3 ∨ x5 ∨ x1 ∨ x2). Clause를 만족하려면 그 안의 literal 하나 이상을 만족.
  • 어떤 formula든 CNF로 변환 가능하지만 크기가 불어날 수 있다.

2. SAT 문제

입력: n개 변수, m개 clause로 이루어진 CNF formula f.

출력: f를 True로 만드는 satisfying assignment가 있으면 그것을, 없으면 NO.

3. 퀴즈 — SAT

Q. f = (x̄1 ∨ x2 ∨ x3) ∧ (x̄2 ∨ x3) ∧ (x̄3 ∨ x1) ∧ (x̄3)
Satisfying assignment가 있으면 쓰고, 없으면 NO.

정답: x1 = False, x2 = True, x3 = False. (x̄3가 unit clause이므로 x3=False가 강제되고, 나머지는 대입해 확인.)

4. k-SAT — 이분법

  • k-SAT: 모든 clause의 크기가 ≤ k.
  • SAT와 k ≥ 3인 k-SAT는 NP-complete (3-SAT, 4-SAT, …).
  • 2-SAT는 polynomial time에 풀린다 — SCC 알고리즘 사용.
Dichotomy: 2-SAT는 쉽고(linear time), 3-SAT부터는 NP-complete다.

5. 입력 단순화 — unit clause 제거

예: (x̄3 ∨ x2) ∧ (x̄1) ∧ (x1 ∨ x4) ∧ (x̄4 ∨ x2) ∧ (x̄3 ∨ x4).

  1. Unit clause (x̄1)를 찾는다. 만족하려면 x1 = False가 강제.
  2. 그 literal을 True로 고정 (x̄1을 True로 = x1을 False로).
  3. x̄1을 포함한 clause는 만족되므로 제거. 반대로 x1을 포함한 clause에서는 x1 literal을 삭제: (x1 ∨ x4) → (x4).
  4. 남은 formula f′: 원래 f가 satisfiable ⟺ f′가 satisfiable.
  5. 새로 생긴 unit clause에 대해 반복. 끝에는 빈 formula(만족) 또는 모든 clause가 정확히 크기 2.

∴ 앞으로는 모든 clause가 크기 2라고 가정하고 알고리즘을 설계한다.

6. Implication graph

논리 문제를 그래프 문제로 바꾼다. 정점 2n개 (literal마다 하나), edge 2m개 (clause마다 2개):

Clause (α ∨ β) → 두 implication edge:

  • ᾱ → β: α를 만족하지 않으면 β를 만족해야.
  • β̄ → α: β를 만족하지 않으면 α를 만족해야.

예: f = (x̄1 ∨ x̄2) ∧ (x2 ∨ x3) ∧ (x̄3 ∨ x1) → edge: x1→x̄2, x2→x̄1, x̄2→x3, x̄3→x2, x3→x1, x̄1→x̄3.

Implication graph 예시: clause (α ∨ β)마다 ᾱ→β, β̄→α 두 edge.

7. SCC 조건 — unsat 판정

  • 경로 x1 ⇝ x̄1이 있으면: x1=True로 두면 연쇄 implication 끝에 x1=False가 강제 → 모순. ∴ x1은 True일 수 없다.
  • x1 ⇝ x̄1과 x̄1 ⇝ x1이 모두 있으면: x1을 True로도 False로도 둘 수 없다 → f는 unsatisfiable.

Unsat 조건: 어떤 변수 i에 대해 xi와 x̄i가 같은 SCC에 있으면 f는 satisfiable하지 않다.

역: 모든 i에 대해 xi, x̄i가 서로 다른 SCC에 있으면 f는 satisfiable하다 (아래 알고리즘으로 satisfying assignment를 직접 구성).

8. 2-SAT 알고리즘

GR1의 SCC 알고리즘과 같은 "sink를 찾아 뜯어내기" 전략:

  1. f를 단순화 (unit clause 제거) → 모든 clause 크기 2.
  2. Implication graph G를 만들고 SCC를 구한다 (topological order 포함).
  3. Sink SCC S를 취한다 → S의 literal들을 모두 True로 설정. (Sink는 outgoing edge가 없으므로 implication을 따라갈 걱정이 없고, incoming edge들은 tail이 이미 만족되어 안전.)
  4. Complement 집합 S̄은 source SCC (§9) → False로 설정. (Incoming edge가 없으니 나중에 문제가 안 되고, False이므로 outgoing implication을 따를 필요도 없다.)
  5. S와 S̄을 제거 (해당 변수는 positive·negative literal이 함께 제거되어 사라짐) → 반복. 빈 그래프가 되면 satisfying assignment 완성.
런타임 O(n + m): 주된 비용은 SCC 구성 (linear time).

9. Key fact — sink의 complement는 source

Key fact: 모든 i에 대해 xi와 x̄i가 다른 SCC에 있으면, S가 sink SCC ⟺ S̄ (complement 집합)이 source SCC.

증명의 핵심은 다음 claim: 경로 α ⇝ β가 있으면 경로 β̄ ⇝ ᾱ도 있다 (역도 성립).

Key fact 증명 스케치:

  1. S가 SCC이면 S̄도 SCC이다: α, β ∈ S가 strongly connected이면 경로 α⇝β, β⇝α가 있고, claim을 적용하면 β̄⇝ᾱ, ᾱ⇝β̄ → ᾱ, β̄도 strongly connected.
  2. S가 sink SCC이면 S̄은 source: S에 outgoing edge가 없으면, claim에 의해 S̄에는 incoming edge가 없다 (edge α→β가 없음 ⟺ edge β̄→ᾱ가 없음). ∴ S̄은 source SCC. (역방향도 동일.)

10. Claim 증명 — 경로 뒤집기

Claim: α ⇝ β 경로가 있으면 β̄ ⇝ ᾱ 경로가 있다.

증명: 경로를 γ0(=α) → γ1 → … → γl(=β)라 하자. Edge γ1 → γ2는 어떤 clause (γ̄1 ∨ γ2)에서 온 implication이다. 같은 clause의 다른 implication은 γ̄2 → γ1. 경로를 따라 이를 반복하면 γ̄l ⇝ γ̄0, 즉 β̄ ⇝ ᾱ 경로가 생긴다. ∎

역방향도 같은 논증. 이로써 2-SAT linear-time 알고리즘의 정확성 증명이 완성된다.

체크리스트

  • CNF, clause, literal, 2n literals를 설명할 수 있다.
  • Unit clause 제거 5단계를 쓸 수 있다.
  • Clause (α ∨ β)에서 edge ᾱ→β, β̄→α를 만들 수 있다.
  • xi와 x̄i가 같은 SCC → unsat인 이유를 설명할 수 있다.
  • Sink SCC → True, complement source SCC → False 할당 전략을 말할 수 있다.
  • Claim (α⇝β ⟹ β̄⇝ᾱ)을 증명할 수 있다.
  • 전체 런타임 O(n+m)을 설명할 수 있다.
