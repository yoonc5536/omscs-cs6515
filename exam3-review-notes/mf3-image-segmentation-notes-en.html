1. Problem — separating foreground from background

An application of max-flow to computer vision: image segmentation. Given an image, separate it into objects; here, just two: foreground and background. Example: picking out the triangle from the rest of the image.

2. Formulation — pixels as vertices

  • View the image as a graph: vertex = pixel.
  • Input is an undirected graph G, with edges between neighboring pixels.
  • Example: a 3×3 pixel image → 9 vertices.

3. Parameters — fi, bi, Pij

  • fi: likelihood (weight) that pixel i is in the foreground.
  • bi: likelihood (weight) that pixel i is in the background.
  • Pij: separation penalty for a neighboring pair — the cost of assigning i and j to different sides.
  • All three are assumed non-negative.

Example setup: white pixels likely foreground (large fi), black pixels likely background (large bi). No penalty for separating pixels of different colors. (Toy example — monochromatic pixels, simple weights.)

4. Partition and weight w(F, B)

Goal: partition vertices into F (foreground) and B (background). Score of a partition:

w(F, B) = Σi∈F fi + Σj∈B bj − Σ(i,j)∈E, separated Pij

  • +fi for each pixel assigned to foreground.
  • +bj for each pixel assigned to background.
  • −Pij for each edge with endpoints on different sides.

Goal: find the partition maximizing w(F, B).

5. Reducing to min-cut — two obstacles

We want to reduce this maximization to the min st-cut problem. Two obstacles:

  • Need to turn max into min.
  • w(F,B) has a subtracted term (−ΣPij). Min st-cut capacities are all non-negative, so the subtraction must become an addition.

6. Reformulation — w(F,B) = L − w′(F,B)

Let L = sum of foreground + background likelihoods over all pixels: L = Σi(fi + bi).

Rewrite each term of w(F,B) as "total minus the opposite side":

  • Σi∈F fi = (total f) − Σj∈B fj
  • Σj∈B bj = (total b) − Σi∈F bi

Hence w(F,B) = L − w′(F,B), where

w′(F,B) = Σi∈F bi + Σj∈B fj + Σseparated Pij

(The separation penalties cancel from both sides and survive as +.)

Key: maximizing w(F,B) ⟺ minimizing w′(F,B) (L is constant). And every term of w′ is non-negative — ready for min st-cut.

7. New problem — minimize w′

Input: undirected graph (image), fi, bi (non-negative) per pixel, Pij (non-negative) per edge.

Goal: partition (F, B) minimizing w′(F,B).

The w′-minimizing partition = the w-maximizing partition = the solution to the original problem.

8. Flow network construction

Reduce to max-flow. Turn the undirected G into a directed flow network:

  1. Neighbor edges → bi-directional: each undirected edge {i, j} becomes i → j and j → i, both with capacity Pij (encodes separation penalties).
  2. Add foreground vertex s: source s. Edge s → i for every pixel i, capacity fi (encodes foreground likelihoods).
  3. Add background vertex t: sink t. Edge i → t for every pixel i, capacity bi (encodes background likelihoods).

Flow network: neighbor edges bidirectional (cap Pij), s→pixel (cap fi), pixel→t (cap bi).

9. Cut capacity = w′(F, B)

Run max-flow on this network to get a min st-cut (MF2's construction). For the cut corresponding to partition (F, B) (s-side = F ∪ {s}, t-side = B ∪ {t}):

Cut-crossing edges (F-side → B-side), three kinds:

  • i → t for i ∈ F: capacity bi → Σi∈F bi
  • s → j for j ∈ B: capacity fj → Σj∈B fj
  • Separated neighbor edge: if i ∈ F, j ∈ B, exactly one direction i → j crosses (j → i is B → F, excluded) → capacity Pij

The sum is exactly w′(F, B)!

So the min st-cut = the partition minimizing w′.

10. Solution summary

Image Segmentation via Max-flow:
    Input: undirected graph (image), f_i, b_i, P_ij
    1. Build flow network:
         - neighbor edges → bidirectional, cap P_ij
         - s → i (cap f_i), i → t (cap b_i)
    2. Run max-flow → f* (maximum flow)
    3. Build min st-cut (MF2): L = {reachable from s in residual graph}
    4. (F, B) = (L − {s}, R − {t})  →  w′ minimum ⟺ w maximum  ✓

The original problem maximized w, but w = L − w′, so the w′-minimizing partition is the answer.

Checklist

  • Write the definition of w(F,B) and its "maximize" goal.
  • Explain w(F,B) = L − w′(F,B) (L is constant).
  • Verify all three terms of w′ are non-negative.
  • Draw the 3-step flow network construction (bi-directional Pij, s→i fi, i→t bi).
  • Explain cut capacity = w′ via the three edge kinds (separated edge: one direction only!).
  • Full pipeline: max-flow → min st-cut (MF2) → w′ minimum = w maximum.
