1. 이번 강의의 두 가지 목표

  1. Max-flow = Min-cut theorem 증명.
  2. Ford-Fulkerson 알고리즘의 정확성(correctness) 증명 — 이 과정에서 Edmonds-Karp의 정확성도 함께 따라 나온다.

MF1에서는 FF의 런타임 O(mC)만 분석하고 "출력된 flow가 정말 max-flow인가"는 증명하지 않았다. 이번 강의에서 그 빈틈을 메운다.

2. Recap + 퀴즈 — Max-flow 검증

FF가 멈추는 조건

FF는 현재 flow f*의 residual graph Gf*에 augmenting path(s → t 경로)가 없을 때 멈춘다. 핵심 Lemma: residual graph에 augmenting path가 없는 flow f*는 max-flow다. (이번 강의에서 증명.)

Q. Flow network와 flow f가 주어졌을 때, f가 max-flow인지 확인하는 데 걸리는 시간은? (n = |V|, m = |E|, big-O로 답하라.)

정답: O(n + m) — linear time.

  • 위 Lemma 덕분이다: f의 residual graph를 만들고 O(n+m), s에서 DFS를 돌려 t에 도달 가능한지 확인 O(n+m).
  • t에 도달 불가 → augmenting path 없음 → f는 max-flow (Yes).
  • t에 도달 가능 → 그 경로로 augment하면 더 큰 flow를 만들 수 있음 → f는 max-flow가 아님 (No).

시험 포인트: "max-flow인지 검증" = residual graph + DFS reachability, O(n+m). FF의 한 라운드와 같은 비용이다.

3. Min-cut 문제 — st-cut과 capacity

  • Cut: 정점을 두 집합으로 나누는 partition. 왼쪽 L, 오른쪽 R.
  • st-cut: s ∈ L, t ∈ R인 cut (s와 t를 분리).
  • Capacity of cut: L → R 방향 edge들의 capacity 합. R → L 방향 edge는 무시한다 (directed graph이므로 방향이 중요).

예제: L = {s, a, b, f}, R = {c, d, e, t} (L이 connected일 필요는 없다). L → R edge 6개: s→c, a→d, a→e, b→e, f→e, f→t. Capacity = 8 + 2 + 2 + 5 + 7 + 3 = 27. c → f 같은 R → L edge는 세지 않는다.

st-cut 예제. 빨간 edge 6개(L→R)의 capacity 합 = 8+2+2+5+7+3 = 27. 점선 c→f는 R→L이라 제외.

4. Min st-cut 문제 정식화

입력: Flow network (directed graph + s, t + positive capacity).

출력: st-cut (L, R) (s ∈ L, t ∈ R) 중 capacity가 최소인 것. Capacity = L → R edge들의 capacity 합 (R → L 무시).

예제: R = {t}, L = 나머지 전부인 cut의 capacity는 12 (t로 들어오는 두 edge). 이것이 min st-cut이다. 왜 최소인지 아는가? → Max-flow = Min-cut 정리 덕분이다: 이 그래프에 size 12인 flow가 존재하므로, flow 12 = cut 12면 둘 다 optimal일 수밖에 없다.

5. 정리 진술 — Max-Flow = Min st-Cut

Theorem. 임의의 flow network에 대해, (max-flow의 size) = (min st-cut의 capacity).

Notation 주의: "st-cut"이라고 부르는 이유는 s와 t를 분리한다는 점을 강조하기 위해서다. 일반 min-cut 문제는 s, t를 분리하지 않아도 된다 — 그래서 min st-cut과 구분한다. 마찬가지로 max-flow도 사실은 "max st-flow"다.

증명 전략: 두 부등식을 각각 증명한다.

  • ① max-flow ≤ min st-cut capacity
  • ② max-flow ≥ min st-cut capacity

6. 증명 ① — max-flow ≤ min-cut

①을 직접 증명하는 대신, 더 쉬운 명제를 증명한다:

충분조건: 임의의 flow f와 임의의 st-cut (L, R)에 대해 size(f) ≤ cap(L, R)이면, ①이 따라 나온다.

왜? f에 대해 max를 취하면(어차피 max-flow도 flow이므로) 좌변은 max-flow가 되고, 우변은 임의의 cut에 대해 성립하므로 min cut을 취해도 된다.

이제 "임의의 flow f, 임의의 st-cut (L,R)에 대해 size(f) ≤ cap(L,R)"을 증명한다. 직관: s에서 t로 가는 flow는 언젠가 L을 탈출해야 하고, 탈출구는 L → R edge들뿐이다. 그 edge들의 capacity 합이 27이면 flow도 27을 넘을 수 없다.

핵심 Claim

Claim: size(f) = fout(L) − fin(L). (L 밖으로 나가는 flow − L 안으로 들어오는 flow)

Claim이 있으면 ①은 즉시: size(f) = fout(L) − fin(L) ≤ fout(L) ≤ cap(L,R). (두 번째 항을 버리면 커지고, 나가는 flow는 각 edge의 capacity를 넘을 수 없으므로.)

7. Claim 증명 — size(f) = fout(L) − fin(L)

  1. fout(L): tail이 L 밖·head가 L 안인 edge들의 flow 합. fin(L): 그 반대.
  2. 여기에 내부 edge(양 끝이 모두 L 안)를 더하고 뺀다 (값은 그대로).
  3. 양의 항들을 합치면: L 안의 모든 정점 v에 대한 (v에서 나가는 총 flow). 음의 항들을 합치면: L 안의 모든 정점 v에 대한 (v로 들어오는 총 flow).
  4. s를 따로 떼어낸다: s로 들어오는 flow는 0이므로, 남는 건 s에서 나가는 flow = size(f).
  5. 나머지 정점 v ∈ L − {s}는 flow conservation으로 out = in → 합이 0.

따라서 size(f) = fout(L) − fin(L). ∎

이 Claim은 ②의 증명에서도 다시 쓰인다.

8. 증명 ② — max-flow ≥ min-cut (cut 구성)

FF가 출력한 flow f*를 가져온다. FF는 residual graph에 augmenting path가 없을 때 멈췄으므로, f*의 residual graph Gf*에는 s → t 경로가 없다.

Cut 구성: L = Gf*에서 s로부터 reachable한 정점들, R = 나머지. t는 reachable하지 않으므로 t ∈ R. s ∈ L이므로 (L, R)은 valid한 st-cut이다.

이제 이 cut의 capacity가 size(f*)와 같음을 보인다 (그러면 ②가 따라 나온다 — 아래 §10 참고).

9. 구성된 cut의 성질

예제: L = {s, a, b, d, e} (residual graph에서 s로부터 reachable), R = {c, f, t}.

L → R edge는 fully saturated

  • 예제: d → t, d → c, s → c.
  • 이유: 만약 v → w (v ∈ L, w ∈ R)가 residual graph에 있었다면 w도 reachable해서 L에 들어가야 한다 — 모순. 따라서 forward edge가 residual에 없다는 것은 flow = capacity라는 뜻.
  • ∴ fout(L) = cap(L, R).

R → L edge는 flow 0

  • 예제: f → e가 유일한 R → L edge.
  • 이유: z → y (z ∈ R, y ∈ L)의 flow가 양수였다면 backward edge y → z가 residual graph에 있어야 하고, y ∈ L이므로 z도 reachable → z ∈ L이 되어 모순. 따라서 flow는 0.
  • ∴ fin(L) = 0.

L = residual graph에서 s로부터 reachable한 정점들. 빨간 L→R edge들은 fully saturated, 점선 f→e는 flow 0. 따라서 size(f*) = cap(L,R).

Claim(§7)에 대입: size(f*) = fout(L) − fin(L) = cap(L,R) − 0 = cap(L,R). ∎

10. 정리 완성 — 따라 나오는 결과들

② 마무리

size(f*) = cap(L,R)을 증명했다. 이제:

  • max-flow ≥ size(f*) (max는 특정 flow f*보다 크거나 같다).
  • cap(L,R) ≥ min st-cut capacity (특정 cut은 min보다 크거나 같다).
  • ∴ max-flow ≥ min st-cut capacity. ①과 합쳐 등식成立. ∎

따라 나오는 결과 (byproducts)

  1. Lemma 증명: augmenting path가 없는 flow f*에 대해 size(f*) = cap(L,R)인 cut을 구성했으므로, 등식이 성립하려면 양쪽이 모두 optimal — 즉 f*는 max-flow다. (§2의 Lemma 증명 완료.)
  2. Ford-Fulkerson 정확성: FF는 augmenting path가 없을 때 멈추므로 출력은 max-flow다. Edmonds-Karp도 같은 조건에서 멈추므로 정확성이 함께 증명된다.
  3. Min-cut 구성법: max-flow f*가 있으면, L = {residual graph에서 s로부터 reachable}로 두면 (L, R)이 min st-cut이다. (Image segmentation 응용에서 사용 예정.)
# Max-flow 검증 (퀴즈 정답의 코드 형태)
def is_max_flow(G, s, t, f):
    Gf = build_residual(G, f)   # O(n + m)
    return not dfs_reaches(Gf, s, t)  # O(n + m) → 총 O(n + m)

# Min st-cut 구성 (max-flow f*로부터)
def min_st_cut(G, s, f_star):
    Gf = build_residual(G, f_star)
    L = {v : reachable from s in Gf}  # DFS/BFS
    R = V - L
    return (L, R)  # cap(L, R) == size(f*)

체크리스트

  • st-cut의 정의와 capacity 정의를 말할 수 있다 (L→R만, R→L 무시).
  • 퀴즈: flow가 max-flow인지 검증하는 시간 O(n+m)을 설명할 수 있다.
  • Claim size(f) = fout(L) − fin(L)의 증명 아이디어를 설명할 수 있다 (내부 edge 더하고 빼기 + conservation).
  • ① max-flow ≤ min-cut의 논리 흐름을 말할 수 있다.
  • ②의 cut 구성법: L = residual graph에서 s로부터 reachable.
  • L→R edge는 saturated, R→L edge는 flow 0인 이유를 설명할 수 있다.
  • 정리로부터 따라 나오는 3가지 (Lemma, FF/EK 정확성, min-cut 구성법)를 말할 수 있다.
  • Min st-cut vs min-cut의 차이를 설명할 수 있다.
