1. 문제 — 이미지를 foreground/background로 분리

Computer vision 문제인 image segmentation에 max-flow를 응용한다. 이미지가 주어졌을 때 물체들을 분리하는 것이 목표이며, 여기서는 간단히 foreground(전경)와 background(배경) 두 개로 나눈다. 예: 이미지에서 삼각형을 나머지(배경)와 구분해내기.

2. 정식화 — 픽셀 = 정점

  • 이미지를 그래프 위에 올려놓고 본다: vertex = pixel.
  • 입력은 undirected graph(무향 그래프) G. 이웃한 픽셀 사이에 edge.
  • 예제: 3×3 픽셀 이미지 → 정점 9개.

3. 파라미터 — fi, bi, Pij

  • fi: pixel i가 foreground일 likelihood(가중치).
  • bi: pixel i가 background일 likelihood(가중치).
  • Pij: 이웃한 픽셀 쌍의 separation penalty(분리 패널티) — i와 j를 서로 다른 쪽에 배정할 때 내는 비용.
  • 세 파라미터 모두 non-negative라 가정.

예제 설정: 흰 픽셀은 foreground일 가능성이 높고(fi 큼), 검은 픽셀은 background일 가능성이 높다(bi 큼). 픽셀 색이 다르면 분리해도 패널티가 없다. (Toy example이라 픽셀이 단색이라 가중치가 단순하다.)

4. Partition과 weight w(F, B)

목표: 정점들을 두 집합 F(foreground), B(background)로 partition한다. Partition의 점수:

w(F, B) = Σi∈F fi + Σj∈B bj − Σ(i,j)∈E, 분리됨 Pij

  • Foreground에 배정한 픽셀마다 fi 획득.
  • Background에 배정한 픽셀마다 bj 획득.
  • 서로 다른 쪽에 배정된 edge마다 분리 패널티 Pij 차감.

목표: w(F, B)를 maximize하는 partition을 찾는다.

5. Min-cut으로의 reduction — 두 가지 걸림돌

이 maximization 문제를 min st-cut 문제로 reduce하고 싶다. 걸림돌 두 가지:

  • Max → min 변환이 필요하다.
  • w(F,B)에는 빼는 항(−ΣPij)이 있다. Min st-cut의 capacity는 전부 non-negative이므로, 빼기를 더하기로 바꿔야 한다.

6. Reformulation — w(F,B) = L − w′(F,B)

L = 모든 픽셀의 foreground + background likelihood 합: L = Σi(fi + bi).

w(F,B)의 각 항을 "전체를 더하고 반대쪽을 빼는" 형태로 고쳐 쓰면:

  • Σi∈F fi = (전체 f 합) − Σj∈B fj
  • Σj∈B bj = (전체 b 합) − Σi∈F bi

따라서 w(F,B) = L − w′(F,B), 여기서

w′(F,B) = Σi∈F bi + Σj∈B fj + Σ분리됨 Pij

(분리 패널티는 양변에서 상쇄되어 +로 남는다.)

핵심: w(F,B)를 maximize하는 것 ⟺ w′(F,B)를 minimize하는 것 (L은 상수). 그리고 w′의 모든 항은 non-negative다 — min st-cut으로 바꿀 준비 완료.

7. 새 문제 — w′ 최소화

입력: 이미지의 undirected graph, 각 픽셀의 fi, bi (non-negative), 각 edge의 Pij (non-negative).

목표: w′(F,B)를 minimize하는 partition (F, B).

w′를 최소화하는 partition = w를 최대화하는 partition = 원래 문제의 해.

8. Flow network 구성

이제 이 문제를 max-flow 문제로 reduce한다. Undirected graph G를 directed flow network로 바꾼다:

  1. 이웃 edge → bi-directional: 각 undirected edge {i, j}를 i → j와 j → i 두 방향으로. Separation penalty를 인코딩하기 위해 두 edge의 capacity를 모두 Pij로 둔다.
  2. Foreground 정점 s 추가: s는 source. 모든 픽셀 i에 edge s → i, capacity fi (foreground likelihood 인코딩).
  3. Background 정점 t 추가: t는 sink. 모든 픽셀 i에 edge i → t, capacity bi (background likelihood 인코딩).

Flow network 구성: 이웃 edge는 양방향(cap Pij), s→픽셀(cap fi), 픽셀→t(cap bi).

9. Cut의 capacity = w′(F, B)

이 flow network에서 max-flow를 돌리면 min st-cut을 얻는다 (MF2의 구성법). Partition (F, B)에 대응하는 cut (s-쪽 = F ∪ {s}, t-쪽 = B ∪ {t})의 capacity를 계산하면:

Cut을 가로지르는 edge (F-쪽 → B-쪽) 세 종류:

  • i ∈ F인 픽셀의 i → t: capacity bi → Σi∈F bi
  • j ∈ B인 픽셀의 s → j: capacity fj → Σj∈B fj
  • 분리된 이웃 edge: i ∈ F, j ∈ B이면 양방향 중 i → j 한 방향만 cut을 가로지른다 (j → i는 B → F라 제외) → capacity Pij

합 = w′(F, B)와 정확히 일치!

따라서 min st-cut을 찾으면 = w′를 최소화하는 partition을 찾은 것이다.

10. 해법 요약

Image Segmentation via Max-flow:
    입력: undirected graph(이미지), f_i, b_i, P_ij
    1. Flow network 구성:
         - 이웃 edge → 양방향, cap P_ij
         - s → i (cap f_i), i → t (cap b_i)
    2. Max-flow 실행 → f* (max flow)
    3. Min st-cut 구성 (MF2): L = {residual graph에서 s로부터 reachable}
    4. (F, B) = (L − {s}, R − {t})  →  w′ 최소 ⟺ w 최대  ✓

원래 문제는 w 최대화였는데, w = L − w′이므로 w′ 최소 partition이 곧 정답이다.

체크리스트

  • 파라미터 fi, bi, Pij의 의미를 말할 수 있다.
  • w(F,B)의 정의와 "maximize" 목표를 쓸 수 있다.
  • w(F,B) = L − w′(F,B) 변환을 설명할 수 있다 (L은 상수).
  • w′의 세 항이 모두 non-negative임을 확인한다.
  • Flow network 구성 3단계 (bi-directional Pij, s→i fi, i→t bi)를 그릴 수 있다.
  • Cut capacity = w′인 이유를 세 종류 edge로 설명할 수 있다 (분리 edge는 한 방향만!).
  • 전체 pipeline: max-flow → min st-cut (MF2) → w′ 최소 = w 최대.
