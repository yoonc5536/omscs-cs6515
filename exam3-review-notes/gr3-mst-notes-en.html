1. The greedy approach

Greedy: from a partial solution, take the locally optimal next move. When does this reach the global optimum?

  • For knapsack, greedy fails on some examples (solved by DP).
  • For MST, greedy works — the topic of this lecture.

2. The MST problem

Input: undirected graph G, weight w(e) on each edge e.

Goal: the smallest connected subgraph — a tree — of minimum total weight: the minimum weight spanning tree.

"Spanning tree" stresses: connected + tree (not a forest).

3. Basic tree facts

  • Tree = connected + acyclic.
  • A tree on n vertices has exactly n − 1 edges. (Need at least n−1 to connect; more creates a cycle.)
  • Exactly one path between every pair of vertices. (Zero → disconnected; two or more → cycle.)
Test used in the proof: connected + exactly n−1 edges → it's a tree.

4. Greedy example — edges by increasing weight

Start from the empty graph; consider edges in increasing weight order, adding each unless it creates a cycle:

  • Weights 1–5: all added (no cycle).
  • Weight 6: skipped (creates a cycle).
  • Weight 7 (five edges): all added. Weight 9: skipped if v–w already connected (cycle), else added.
  • Weight 12: skipped.

The result is an MST. Formalizing this gives Kruskal's algorithm.

5. Kruskal's algorithm

Kruskal(G):                          # undirected, edge weights
    1. sort edges by increasing weight (e.g. mergesort)
    2. X ← ∅                          # edges placed into the MST so far
    3. for each edge e = (v, w) in sorted order:
         if adding e to X creates no cycle → X ← X ∪ {e}
    4. return X

"Creates a cycle?" test: in the subgraph of X, if v and w are in the same component, a v–w path already exists → e creates a cycle. Otherwise add it.

6. Runtime analysis — O(m log n)

  • Step 1 (sorting): O(m log n) (= O(m log m)).
  • Step 3 (checks + merges): Union-Find at O(log n) per operation. Look up c(v), c(w), merge on insertion. At most m operations → O(m log n).
Total O(m log n). The lecture's focus is the correctness proof, not the data structure.

7. Correctness idea — induction

Induction hypothesis: current X is correct so far = a subgraph of some MST T (X ⊆ T). Now consider edge e = (v, w) with v, w in different components (no cycle).

Claim: X ∪ {e} is also correct so far, i.e. a subgraph of some MST T′. (T′ may differ from T — we only need to be heading toward some MST.)

Key observation: let S = c(v) (v's component). No edge of X crosses S–S̄ (components are maximal). But e crosses S–S̄, and by the sorted order e is a minimum-weight edge crossing S–S̄. → exactly the cut property hypothesis.

8. Cut definition

A cut partitions vertices into S and S̄ (complement). cut(S, S̄) = the set of edges with one endpoint in S and the other in S̄ (edges "crossing" S–S̄).

cut(S, S̄): the edges crossing between S and S̄ (red).

9. The cut property (statement)

Cut property: assume

  • X is correct so far (a subgraph of some MST T).
  • No edge of X crosses cut(S, S̄).
  • e* is a minimum-weight edge crossing cut(S, S̄) (any one if tied).

Conclusion: X ∪ {e*} is still correct so far — a subgraph of some MST T′.

Intuition: given a tree T without e*, add e* and drop one edge from the created cycle to get a tree of no greater weight (proved below).

10. Cut property → Kruskal's

When Kruskal's adds e* = (v, w): take S = c(v) (v's component). Maximality means no edge of X crosses S–S̄; the sorted order makes e* a minimum-weight crossing edge. → the cut property applies → X ∪ {e*} stays correct so far. ∎

11. Proof — constructing T′

Fix: G, X ⊆ T (T an MST), cut(S, S̄) crossed by no edge of X, minimum-weight crossing edge e* (endpoints a, b). Goal: build an MST T′ with X ∪ {e*} ⊆ T′.

  • Easy case: e* ∈ T → T′ = T. Done.
  • Hard case: e* ∉ T. T ∪ {e*} creates a cycle C (a tree plus one edge — T has an a–b path).

T is connected, so the a–b path crosses S–S̄ at least once. Pick such a crossing edge of T and call it e′ (it lies on cycle C since e* also crosses the cut). Set T′ = T ∪ {e*} − {e′}.

12. T′ is a tree

Test: connected + exactly n−1 edges.

  • Edge count: T had n−1; one added, one removed → still n−1. ✓
  • Connected: for any y, z take their T-path P. If P avoids e′, it's a T′-path. If P uses e′ = (c, d), replace e′ by the rest of cycle C (a c–d path P′ lying in T′). (This gives a walk; trimming yields a path.) ✓

In fact removing any edge of the cycle yields a tree — one of the two key proof ideas.

13. T′ is an MST

  • weight(T′) = weight(T) + w(e*) − w(e′).
  • e* is minimum-weight across the cut and e′ also crosses it, so w(e*) ≤ w(e′). → weight(T′) ≤ weight(T). T is an MST, so weight(T′) = weight(T): T′ is an MST. ∎

Two takeaways:

  • Statement: a minimum-weight edge across a cut belongs to some MST.
  • Proof idea: adding an edge to a tree creates a cycle; removing any cycle edge gives a new tree.

14. Prim's algorithm

Prim's correctness can also be proved via the cut property (an MST algorithm similar in shape to Dijkstra's). Try proving Prim's yourself with the cut property as an exercise.

Glossary

TermMeaning
MST (minimum spanning tree)A spanning tree of minimum total weight.
Spanning treeA tree covering all vertices (connected + acyclic). n vertices → exactly n−1 edges.
Tree factA tree on n vertices has exactly n−1 edges, and exactly one path between every pair of vertices.
GreedyA strategy that repeatedly makes the locally optimal choice from a partial solution. Works for MST but fails for Knapsack.
Locally optimalThe choice that looks best at the current step; whether it reaches the global optimum varies by problem.
Kruskal's algorithmConsider edges in increasing weight order; add an edge unless it creates a cycle. Runtime O(m log n).
Union-FindThe data structure for Kruskal's cycle test; O(log n) per operation (details skipped in the lecture).
Correct so farThe state in which the current edge set X is a subgraph of some MST T. The induction hypothesis.
CutA partition of the vertices into S and S̄ (complement). cut(S, S̄) is the set of edges crossing between S and S̄.
Complement (S̄)The complement of S. In a cut: "one end in S, the other in S̄."
Cut propertyIf X is correct so far and no edge of X crosses cut(S, S̄), then for the minimum-weight crossing edge e*, X ∪ {e*} is also correct so far. I.e. "the minimum-weight edge crossing a cut belongs to some MST."
T′ = T ∪ {e*} − {e′}The new MST constructed in the cut-property proof: adding e* to T creates a cycle C, and one cut-crossing edge e′ on C is removed.
Removing a cycle edgeAdding one edge to a tree creates a cycle, and removing any edge of that cycle yields a tree again. A core proof idea.
Component c(v)The connected component of v in the subgraph of current X. Kruskal's proof forms a cut with S = c(v).
Prim's algorithmAn MST algorithm with a Dijkstra-like form. Its correctness also follows from the cut property.

Checklist

  • Write Kruskal's pseudocode and explain O(m log n) (sorting + union-find).
  • Define cut and cut(S, S̄).
  • State the cut property precisely (three assumptions + conclusion).
  • Connect cut property → Kruskal's (S = c(v)).
  • Draw the T′ = T ∪ {e*} − {e′} construction.
  • Prove T′ is a tree (connected + n−1 edges).
  • Prove T′ is an MST (w(e*) ≤ w(e′)).
  • Know that Prim's follows from the cut property too.
